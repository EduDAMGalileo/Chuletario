3Bases de datos y esquemas

Jerarquía: servidor → base de datos → esquema → tabla. En MySQL «esquema» y «base de datos» son lo mismo. En PostgreSQL no se puede consultar otra base de datos desde la conexión actual, pero sí otro esquema: esquema.tabla.

4Identificadores y comillas

MySQLPostgreSQL
SELECT `order` FROM t;
SELECT "order" FROM t;
nombre reservado o con espacios
SELECT "texto";
SELECT 'texto';
los textos solo con comillas simples
'It\'s'
'It''s'
comilla dentro de un texto
'línea\n'
E'línea\n'
secuencias de escape

Cuidado: PostgreSQL pasa a minúsculas los nombres sin comillas. Si creas CREATE TABLE "Alumno", tendrás que escribir siempre "Alumno" con comillas. Lo más cómodo es usar siempre snake_case en minúsculas.

8Comportamientos que cambian

WHERE nombre = 'ana'

la igualdad también distingue mayúsculas
SELECT 5 / 2; -- 2.5000
SELECT 5 / 2; -- 2
división entera; usa 5 / 2.0 o CAST
SELECT 'a' || 'b'; -- 0
SELECT 'a' || 'b'; -- ab
|| concatena
sin equivalente
FULL OUTER JOIN
PostgreSQL sí lo tiene

En GROUP BY PostgreSQL es estricto: toda columna del SELECT tiene que estar agrupada o dentro de una función agregada (salvo que agrupes por la clave primaria).

11Transacciones

En PostgreSQL el DDL es transaccional: un CREATE, ALTER o DROP dentro de una transacción se puede deshacer. En MySQL provocan un COMMIT implícito.

Cuidado: si una sentencia falla dentro de un BEGIN, la transacción queda abortada y hay que hacer ROLLBACK antes de seguir.
