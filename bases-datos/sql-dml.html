Qué manipula

El DML trabaja con el contenido de las tablas: añade filas, las modifica y las borra. La estructura la define el DDL; consultar es cosa de las consultas.

Las tres órdenes

INSERTañadir filas
UPDATEmodificar filas existentes
DELETEborrar filas

1Qué es DML

El Data Manipulation Language es la parte de SQL que cambia los datos guardados. A diferencia del DDL, sus cambios se pueden agrupar y deshacer con transacciones.

Regla de oro: UPDATE y DELETE sin WHERE afectan a toda la tabla. Prueba antes el WHERE con un SELECT, o trabaja dentro de una transacción.

2INSERT

Columnas listadassolo rellenas esas; el resto toma su DEFAULT
Sin lista de columnashay que dar un valor por cada columna, en orden
INSERT … SELECTcopia filas de otra consulta

Las columnas AUTO_INCREMENT no se indican: el gestor pone el id. Los textos y fechas van entre comillas simples.

3UPDATE

El SET puede usar el valor actual de la columna (nota = nota + 1). El WHERE decide qué filas se cambian; sin él, todas.

4DELETE

DELETE … WHEREborra las filas que cumplen la condición
DELETE sin WHEREborra todas las filas (mejor TRUNCATE)
Con clave foráneapuede fallar o propagarse según ON DELETE

Si otras tablas apuntan a esta con una clave foránea, el borrado depende de ON DELETE: RESTRICT lo impide, CASCADE borra también las hijas, SET NULL las desvincula.

5UPSERT

Insertar y, si la fila ya existe (choca con una clave), actualizarla en vez de fallar. La sintaxis cambia según el gestor.

Útil para «crear o actualizar» sin comprobar antes si existe. En PostgreSQL, EXCLUDED es la fila que se intentaba insertar. Ver PostgreSQL.
