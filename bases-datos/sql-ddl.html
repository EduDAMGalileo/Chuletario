Qué define

El DDL crea y modifica el esqueleto de la base de datos: qué tablas hay, qué columnas y de qué tipo, y las reglas que deben cumplir los datos. Es el resultado directo del modelo relacional.

Órdenes DDL

CREATEcrear base, tabla, índice, vista
ALTERmodificar una estructura existente
DROPeliminarla
TRUNCATEvaciar una tabla

1Qué es DDL

El Data Definition Language es la parte de SQL que define y modifica la estructura de los datos, no su contenido. Con él creas la base, las tablas y sus reglas.

Los ejemplos usan las tablas curso(id, nombre, horas) y alumno(id, nombre, email, nota, fecha_nac, curso_id). En muchos gestores, las órdenes DDL confirman la transacción automáticamente (no se pueden deshacer con ROLLBACK).

2Crear base y tablas

AUTO_INCREMENT (MySQL) genera el id solo. En PostgreSQL es SERIAL o GENERATED AS IDENTITY; ver PostgreSQL.

4Restricciones

PRIMARY KEYidentifica la fila; única y no nula
FOREIGN KEY … REFERENCESenlaza con la clave de otra tabla
NOT NULLobligatorio
UNIQUEsin valores repetidos
DEFAULT valorvalor por defecto si no se indica
CHECK (condición)valida el dato al insertar/actualizar
ON DELETE CASCADEal borrar la padre, borra las hijas
ON DELETE SET NULLal borrar la padre, pone la FK a NULL
ON DELETE RESTRICTimpide borrar si hay hijas (por defecto)

Las restricciones son la integridad del modelo relacional puesta en práctica: el gestor rechaza los datos que las incumplen. Puedes nombrarlas con CONSTRAINT nombre … para referirte a ellas después.

5ALTER TABLE

ALTER cambia la estructura ya creada: añadir o quitar columnas, cambiar tipos, añadir restricciones. La sintaxis exacta (MODIFY en MySQL, ALTER COLUMN en PostgreSQL) varía entre gestores.

6DROP y TRUNCATE

DELETE (DML)borra filas concretas; se puede deshacer en transacción
TRUNCATE (DDL)vacía toda la tabla, rápido, reinicia el contador
DROP (DDL)elimina la tabla y su estructura

Cuidado: TRUNCATE y DROP no piden confirmación ni suelen poder deshacerse. Para borrar filas seleccionadas usa DELETE con WHERE.

7Índices

Un índice acelera las búsquedas por una columna, como el índice de un libro. Se paga con algo más de espacio y escrituras más lentas.

Las claves PRIMARY KEY y UNIQUE ya crean un índice automáticamente. Indexa las columnas por las que filtras o unes (WHERE, JOIN) a menudo, no todas.

8Vistas

Una vista es una consulta guardada con nombre: se usa como si fuera una tabla, pero no almacena datos, los calcula al consultarla.

Sirven para simplificar consultas complejas, reutilizarlas y dar acceso solo a ciertas columnas (útil con permisos).

9Explorar el esquema

SHOW DATABASES;lista las bases de datos
SHOW TABLES;tablas de la base actual
DESCRIBE alumno;columnas, tipos y claves
SHOW CREATE TABLE alumno;el DDL completo que la creó

Son órdenes de MySQL. En PostgreSQL se usan los metacomandos de psql (\l, \dt, \d alumno); ver PostgreSQL.
