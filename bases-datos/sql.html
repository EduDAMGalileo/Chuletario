SQL

El lenguaje de las bases relacionales, repartido en sus cinco sublenguajes: DDL, DML, consultas (DQL), DCL y TCL. Sintaxis MySQL.

IntroducciónModelo ER-EERModelo relacionalSQLPostgreSQL

La idea

SQL (Structured Query Language) es el lenguaje estándar para hablar con las bases de datos relacionales. Se organiza en familias de instrucciones según para qué sirven; cada una tiene aquí su propia página.

Los cinco sublenguajes

DDLdefinir la estructura: CREATE, ALTER, DROP
DMLmanipular datos: INSERT, UPDATE, DELETE
DQLconsultar: SELECT
DCLpermisos: GRANT, REVOKE
TCLtransacciones: COMMIT, ROLLBACK

Elige un sublenguaje. Si empiezas, el orden natural es DDL (crear las tablas), DML (meter datos), Consultas (sacarlos) y, más adelante, DCL y TCL.

Los sublenguajes

DDLDefinir la estructura: CREATE, ALTER, DROP, restricciones, índices y vistas.DMLManipular datos: INSERT, UPDATE, DELETE y UPSERT.Consultas (DQL)SELECT: filtros, orden, funciones, agrupación, JOIN y subconsultas.DCLPermisos: usuarios, GRANT, REVOKE y roles.TCLTransacciones: COMMIT, ROLLBACK, SAVEPOINT, ACID y aislamiento.
