La idea

Eclipse es un IDE libre, veterano y muy usado para Java (y ampliable a otros lenguajes con plugins). Todo gira en torno a un workspace (espacio de trabajo) que contiene tus proyectos.

Conceptos clave

Workspacecarpeta con tus proyectos y ajustes
Perspectivadisposición de vistas para una tarea
Build Pathqué usa el proyecto para compilar
JRE / JDKla versión de Java del proyecto

1Qué es Eclipse

Un entorno de desarrollo integrado, gratuito y de código abierto, referencia histórica en Java. Muy usado en formación y empresa; en los últimos años comparte terreno con IntelliJ IDEA y VS Code.

Eclipse IDE for Java Developersla edición para empezar con Java
Eclipse IDE for Enterprise Javaañade web y Jakarta EE
Pluginsamplían el IDE (PyDev, EGit, etc.)

2Instalación y workspace

Necesita un JDK instalado (no basta el JRE si vas a compilar). Al arrancar, Eclipse pide la carpeta del workspace.

JDKel kit de desarrollo de Java (incluye el compilador)
Workspacecarpeta que agrupa proyectos y su configuración
Varios workspacespuedes tener uno por asignatura o cliente
Window › Preferencestoda la configuración del entorno

Comprueba la versión de Java del entorno en Window › Preferences › Java › Installed JREs. Debe apuntar a un JDK, no solo a un JRE.

Si «pierdes» un panel, recupéralo en Window › Show View, o restablece con Window › Perspective › Reset Perspective.

4Crear un proyecto

File › New › Java Projectun proyecto Java normal
File › New › Maven Projectproyecto gestionado con Maven
srccarpeta del código fuente
PaqueteNew › Package, antes de las clases
ClaseNew › Class; marca public static void main si es el punto de entrada

Eclipse compila automáticamente al guardar (Build Automatically): no hay un paso manual de compilar como en la terminal.

5El Build Path

El build path define qué necesita el proyecto para compilar: la versión de Java, las librerías (JAR) y las carpetas de fuentes. Se abre con clic derecho en el proyecto › Build Path o Properties › Java Build Path.

Sourcecarpetas con código fuente (src)
Librarieslos JAR y el JRE del sistema
Add External JARsañadir una librería descargada a mano
Add Libraryañadir JUnit, el JRE, etc.
Order and Exportorden y qué se exporta al empaquetar

Cuidado: si usas Maven, las dependencias las gestiona el pom.xml, no el build path a mano. Mézclalos y tendrás librerías duplicadas o que desaparecen al actualizar.

6Escribir código

Ctrl+Espacioautocompletar
Ctrl+1Quick Fix: soluciones a un error
sysout + Ctrl+Espaciogenera System.out.println()
Ctrl+Shift+Oorganizar los import
Ctrl+Shift+Fformatear el código
Alt+Shift+Smenú Source: getters/setters, constructores...

El subrayado rojo marca errores; el amarillo, avisos. Pasa el ratón por encima o pulsa Ctrl+1 sobre el error para que Eclipse proponga el arreglo.

7Ejecutar y depurar

Ctrl+F11ejecutar
F11ejecutar en modo depuración
Doble clic al margenponer o quitar un breakpoint
F5entrar en el método (step into)
F6siguiente línea (step over)
F8continuar hasta el siguiente breakpoint

En la perspectiva Debug, la vista Variables muestra el valor de todo en el momento en que el programa está parado. Ver también el depurador en general.

8Integrar Git

Eclipse trae EGit integrado. Clic derecho en el proyecto › Team para todo lo de Git.

Team › Share Projectponer el proyecto bajo control de versiones
Team › Commitconfirmar cambios
Team › Push / Pullsincronizar con el remoto (GitHub)
Git Stagingvista para preparar y confirmar
Git Repositoriesvista para clonar y gestionar repos

Añade un .gitignore que excluya bin/, target/ y los ficheros de proyecto de Eclipse (.settings/, .classpath, .project) si el equipo usa otros IDE.

10Consejos

VersionesEclipse publica una versión cada trimestre (2024-12, 2025-03...)
Java del proyectorevisa que el Compiler compliance level coincida con tu JDK
Un error raroProject › Clean recompila desde cero
Formato del equipocomparte el formatter para un estilo común
No versionarbin/, .settings/, .classpath, .project

Si vienes de la terminal, recuerda: aquí no ejecutas javac a mano; Eclipse compila al guardar y ejecuta con Ctrl+F11.
