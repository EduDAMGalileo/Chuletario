La idea

Un IDE (Entorno de Desarrollo Integrado) reúne en un solo programa todo lo necesario para programar: editar, ejecutar, depurar y gestionar el proyecto. Un buen entorno hace de multiplicador: escribes mejor código en menos tiempo.

1Qué es un IDE

Un IDE integra las herramientas del desarrollo en una sola interfaz. En vez de saltar entre el editor, la terminal, el compilador y el depurador, lo tienes todo conectado y trabajando junto.

IDE = Integrated Development Environment. La palabra clave es «integrado»: las piezas se comunican entre sí.

Al aprender, conviene entender también qué hace el IDE por debajo (compilar, ejecutar): así no dependes de los botones si algún día trabajas desde la terminal.

4IDE o editor

Editor de códigoligero y rápido; funciones extra por extensiones (VS Code)
IDE completotodo integrado y potente para un lenguaje; más pesado (IntelliJ)

La frontera se difumina: VS Code con extensiones se acerca a un IDE, y muchos IDEs son cada vez más ligeros. Elige según el proyecto y el lenguaje.

6El depurador

La herramienta que más diferencia a un IDE de un editor: ejecutar el programa paso a paso para ver qué hace por dentro, en lugar de llenar el código de print.

Punto de rupturabreakpoint: el programa se para en esa línea
Paso a pasoejecutar una línea cada vez (step)
Entrar / salirmeterse en una función o salir de ella
Inspeccionarver el valor de las variables en ese momento
Pila de llamadasqué función llamó a cuál

Saber usar el depurador es de las habilidades que más tiempo ahorra. Un breakpoint bien puesto vale por veinte print.
