La idea

VS Code es un editor de código ligero, gratuito y multiplataforma. No es un IDE completo de serie como Eclipse, pero con extensiones se acerca mucho, para casi cualquier lenguaje.

El atajo que lo abre todo

Si te quedas con uno, que sea Ctrl+Shift+P: la paleta de comandos. Desde ahí se ejecuta cualquier acción del editor sin buscarla en menús.

En macOS, cambia Ctrl por Cmd en casi todos los atajos.

1Qué es VS Code

Un editor extensible construido sobre tecnología web (Electron). Rápido de arrancar, con un enorme catálogo de extensiones que le añaden lenguajes, depuradores y herramientas. Es hoy el editor más usado.

Editor vs IDEde base es un editor; las extensiones lo convierten casi en IDE
MultiplataformaWindows, macOS y Linux
IntelliSenseautocompletado inteligente según el lenguaje
No confundir«VS Code» ≠ «Visual Studio», el IDE grande de Microsoft

Alternativa 100% libre: VSCodium, la misma base sin la telemetría ni la marca de Microsoft.

2La interfaz

Cinco zonas que conviene reconocer:

Activity Barla columna de iconos de la izquierda (explorador, buscar, Git, depurar, extensiones)
Side Barel panel que abre cada icono; el explorador de archivos por defecto
Editorla zona central; admite pestañas y dividir en columnas
Panelabajo: terminal, problemas, salida, consola de depuración
Status Barla barra inferior: rama de Git, errores, lenguaje, codificación
Ctrl+Bmostrar / ocultar la barra lateral
Ctrl+\dividir el editor en dos
Abrir carpetaVS Code trabaja sobre una carpeta (el workspace), no sobre ficheros sueltos

Trabaja siempre abriendo la carpeta del proyecto (File › Open Folder): así funcionan la búsqueda global, Git y las rutas relativas.

3La paleta de comandos

El corazón de VS Code. Un buscador de todo lo que el editor puede hacer; empieza a escribir y filtra.

Ctrl+Shift+Pabrir la paleta de comandos
Ctrl+Pabrir un fichero por nombre (Quick Open)
>prefijo de comando (lo que pone Ctrl+Shift+P)
@ir a un símbolo del fichero (función, clase)
:ir a una línea concreta
?ver la ayuda de qué prefijos hay

Todos comparten el mismo cuadro: Ctrl+P y luego escribes >, @ o : para cambiar de modo. Si no recuerdas un atajo, casi siempre está en la paleta escribiendo lo que quieres hacer.

4Moverse rápido

Ctrl+Psaltar a un fichero por nombre
Ctrl+Shift+Oir a un símbolo (método, clase) del fichero
Ctrl+Gir a una línea
F12ir a la definición (Ctrl+clic también)
Alt+← / →atrás / adelante en el historial de navegación
Ctrl+Tabcambiar entre pestañas abiertas

La barra de breadcrumbs (migas) sobre el editor muestra la ruta y el símbolo actual; es clicable para navegar por la estructura del fichero.

5Editar

Lo que más productividad da: los cursores múltiples, para editar varios sitios a la vez.

Alt+clicañadir un cursor donde pulses
Ctrl+Dseleccionar la siguiente aparición de lo seleccionado
Ctrl+Shift+Lseleccionar todas las apariciones a la vez
Alt+↑ / ↓mover la línea arriba / abajo
Shift+Alt+↓duplicar la línea
Ctrl+/comentar / descomentar
Shift+Alt+Fformatear el documento
F2renombrar el símbolo en todo el proyecto

Ctrl+D repetido es el flujo estrella: seleccionas una palabra, pulsas Ctrl+D varias veces para ir cazando cada aparición y las editas todas juntas.

6Buscar y reemplazar

Ctrl+Fbuscar en el fichero actual
Ctrl+Hbuscar y reemplazar en el fichero
Ctrl+Shift+Fbuscar en todo el proyecto
Ctrl+Shift+Hreemplazar en todo el proyecto
.*activar expresiones regulares en el cuadro de búsqueda
Aadistinguir mayúsculas; el botón ab busca palabra completa

La búsqueda global admite filtros por tipo de fichero (files to include: *.js) y excluir carpetas, muy útil para no buscar en node_modules.

7Terminal integrada

Una terminal completa dentro del editor, en la carpeta del proyecto. Evita saltar a otra ventana para lanzar comandos.

Ctrl+`abrir / cerrar la terminal (la tecla del acento grave)
Ctrl+Shift+`abrir una terminal nueva
+ / listavarias terminales a la vez; se cambia en el desplegable
Elegir shellBash, PowerShell, etc. desde el desplegable de la terminal

En teclados españoles, si Ctrl+` no responde, míralo en Terminal › New Terminal o reasigna el atajo (sección 11). Aquí van muy bien las chuletas de terminal y Git.

8Depurar

VS Code trae un depurador visual; cada lenguaje aporta el suyo mediante una extensión. Se controla desde la vista Run and Debug.

F5iniciar / continuar la depuración
Clic al margenponer o quitar un breakpoint (punto de ruptura)
F10siguiente línea (step over)
F11entrar en la función (step into)
Shift+F5detener
launch.jsonconfiguración de cómo arrancar la depuración

Con el programa parado en un breakpoint, la vista de la izquierda muestra las variables y la pila de llamadas, y puedes evaluar expresiones en la consola de depuración. Ver el depurador en general.

9Git integrado

La vista Source Control (icono de ramas en la Activity Bar) integra Git sin salir del editor.

Ctrl+Shift+Gabrir el panel de control de código
+ (Stage)preparar cambios para el commit
✓ (Commit)confirmar con el mensaje escrito arriba
Synchacer push y pull con el remoto
Clic en un ficherover el diff de lo cambiado
Barra de estadoabajo a la izquierda: la rama actual; clic para cambiarla

El margen del editor marca con colores las líneas añadidas, cambiadas o borradas respecto al último commit (el gutter). La extensión GitLens añade aún más (autoría línea a línea, historial). Ver GitHub.

10Extensiones

Lo que hace grande a VS Code. Se instalan desde el icono de extensiones (Ctrl+Shift+X) o el Marketplace.

Packs de lenguajePython, Extension Pack for Java, C/C++...
Linters / formatoESLint, Prettier: avisan de errores y formatean
RemotasWSL, SSH, Dev Containers: editar en otra máquina o contenedor
UtilidadGitLens, Live Server, REST Client
Temascolores e iconos del editor

No instales de todo: cada extensión consume memoria y puede ralentizar el arranque. Instala la del lenguaje que uses y poco más; revisa de vez en cuando las que ya no necesitas.

11Ajustes y atajos

Todo es configurable. Los ajustes tienen una interfaz gráfica y, por debajo, un fichero JSON.

Ctrl+,abrir los ajustes (Settings)
settings.jsonlos ajustes en texto (paleta: Open User Settings (JSON))
Usuario vs Workspaceajustes globales o solo para este proyecto (carpeta .vscode/)
Ctrl+K Ctrl+Seditar los atajos de teclado
keybindings.jsontus atajos personalizados
Ctrl+K Ctrl+Tcambiar el tema de color

Los ajustes de Workspace se guardan en .vscode/settings.json dentro del proyecto: compártelos por Git para que el equipo use el mismo formato, pero no metas ahí nada personal o con secretos.
