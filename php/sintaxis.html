Funciones de cadena

strlen($s)longitud en bytes
mb_strlen($s)longitud en caracteres (con tildes y ñ)
strtoupper() strtolower()a mayúsculas / minúsculas
ucfirst() ucwords()primera letra / cada palabra en mayúscula
trim() ltrim() rtrim()quita espacios de los extremos
str_contains($s, 'x')¿contiene? (PHP 8)

Cuidado: strlen("año") devuelve 4, porque la ñ ocupa dos bytes en UTF-8. Para texto en español usa las funciones mb_: mb_strlen, mb_substr, mb_strtoupper.

7Arrays

Funciones de array

count($a)número de elementos
in_array($v, $a)¿contiene el valor?
array_search($v, $a)clave del valor, o false
array_key_exists($k, $a)¿existe la clave?
array_keys() array_values()solo las claves / solo los valores
array_push() array_pop()añadir / sacar por el final
array_unshift() array_shift()añadir / sacar por el principio
array_merge($a, $b)unir arrays
array_slice($a, 1, 2)trozo: desde 1, 2 elementos
sort() rsort()ordena por valor y renumera las claves
asort() arsort()ordena por valor manteniendo las claves
ksort() krsort()ordena por clave
usort($a, $fn)ordena con tu propia comparación
array_sum() max() min()suma, máximo y mínimo
array_unique()quita duplicados
array_reverse()invierte el orden
range(1, 10)[1, 2, ..., 10]

Las funciones de ordenación modifican el array original y devuelven true: no hagas $a = sort($a).

10Despistes habituales

nombre = 1;falta el $: todas las variables lo llevan
"a" + "b"el + suma; para unir texto es .
'Hola $x'las comillas simples no sustituyen variables
if ($x = 5)asigna en vez de comparar: es == o ===
$a['clave']si no existe, da un aviso: usa $a['clave'] ?? valor
echo $array;muestra «Array»: usa print_r o var_dump

Headers already sent: header(), setcookie() y session_start() tienen que ir antes de enviar cualquier salida. Un espacio o una línea en blanco antes de <?php, o después de un ?> final, ya cuenta como salida.

Para ver los errores mientras desarrollas: ini_set('display_errors', '1'); y error_reporting(E_ALL); al principio del script.
