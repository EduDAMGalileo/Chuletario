PHP

El lenguaje del lado del servidor para páginas web dinámicas. De la sintaxis básica a los formularios, las sesiones, la orientación a objetos y las bases de datos.

Sintaxis básicaFormulariosCookies y sesionesPOOBases de datos

La idea

PHP se ejecuta en el servidor: cuando el navegador pide una página .php, el servidor ejecuta el script y devuelve el HTML que este genera. El navegador nunca ve el código PHP, solo su resultado.

navegadorpide /tienda.php

PHPlee datos, consulta la BD

Las chuletas de PHP, agrupadas por temas. Empieza por la sintaxis, sigue con lo propio de la web (formularios y sesiones) y termina con objetos y bases de datos, que es como se organiza una aplicación real.
