La teoría (los cuatro pilares, qué es encapsular o heredar) es la misma que en Java. Aquí se ve la sintaxis de PHP.

1Clase y objeto

Por convenio, una clase por fichero y con el mismo nombre: Coche.php. Las clases en PascalCase, métodos y propiedades en camelCase.

2Constructor y promoción de propiedades

El constructor se llama __construct y se ejecuta al hacer new. Solo puede haber uno (no hay sobrecarga): para variantes se usan parámetros con valor por defecto o métodos estáticos.

3Visibilidad y encapsulación

publicaccesible desde cualquier sitio (por defecto en los métodos)
protecteddesde la clase y sus hijas
privatesolo desde la propia clase

Desde PHP 8.4 existen los property hooks (get y set dentro de la propiedad) y la visibilidad asimétrica (public private(set)), que evitan escribir muchos getters y setters.

4readonly e inmutables

Una propiedad readonly pública hace el papel de un getter sin escribirlo. Es lo más parecido a un record de Java.

5static, self y constantes

self::la clase donde está escrito el código
static::la clase con la que se llamó (enlace estático tardío)
parent::la clase padre
Clase::classel nombre completo de la clase como texto, con su namespace
$obj::classla clase de un objeto (PHP 8)

6Herencia

El constructor del padre no se ejecuta solo si la hija tiene el suyo: hay que llamar a parent::__construct(...). Si la hija no define constructor, se usa el del padre.

7Clases abstractas

No se pueden instanciar: son una plantilla con parte del código hecho y métodos abstract que cada hija está obligada a escribir.

8Interfaces

Un contrato: qué métodos públicos debe tener una clase, sin decir cómo. Una clase puede implementar varias interfaces.

Abstractapuede tener propiedades y código; solo se hereda de una
Interfazsolo firmas de métodos públicos y constantes; se implementan varias
Usa una abstracta si...las clases comparten código y son "del mismo tipo"
Usa una interfaz si...clases sin relación deben poder hacer lo mismo

9Traits

Un bloque de propiedades y métodos que se "pega" dentro de varias clases. Sirve para reutilizar código entre clases que no tienen un padre común.

10Enums

PHP 8.1: un tipo con un conjunto cerrado de valores. Mejor que constantes sueltas o cadenas mágicas.

11Métodos mágicos

Métodos con doble guion bajo que PHP llama solo en ciertas situaciones.

__construct()al crear con new
__destruct()al liberar el objeto
__toString()al usarlo como texto: echo $obj, "$obj"
__get($n) __set($n, $v)al leer o escribir una propiedad que no existe o no es accesible
__isset($n) __unset($n)al usar isset o unset sobre ellas
__call($m, $args)al llamar a un método que no existe
__callStatic($m, $args)lo mismo, de forma estática
__invoke(...)al usar el objeto como función: $obj(5)
__clone()tras copiar con clone
__serialize() __unserialize()al serializar con serialize

14Namespaces y autocarga

Un namespace agrupa clases como una carpeta y evita choques de nombres. La autocarga hace el require de cada clase solo cuando se usa por primera vez.

Tras cambiar el composer.json se ejecuta composer dump-autoload. Con PSR-4, el namespace debe coincidir con la carpeta y el nombre de la clase con el del fichero.
