XPath

Cómo seleccionar nodos de un documento XML. Las funciones marcadas como 2.0 no están en XPath 1.0.

Documento de ejemplo: biblioteca.xml (todos los resultados de esta página salen de aquí)

1Rutas

/nodo raíz del documento
/biblioteca/libroruta absoluta: libros hijos de biblioteca
libro/tituloruta relativa al nodo actual
//titulotitulo en cualquier nivel
//libro//text()todos los textos dentro de libros
.nodo actual
..nodo padre
*cualquier elemento
@idatributo id
@*cualquier atributo
text()nodos de texto
node()cualquier nodo (elemento, texto, comentario…)
//titulo | //autorunión de dos resultados

Una ruta que empieza por / es absoluta. // recorre todo el árbol: es cómodo pero lento en documentos grandes.

2Predicados: filtrar con [ ]

libro[1]el primero (se cuenta desde 1)
libro[last()]el último
libro[last() - 1]el penúltimo
libro[position() <= 2]los dos primeros
libro[@categoria = 'novela']por valor de atributo
libro[@id]que tengan el atributo
libro[not(@id)]que no lo tengan
libro[precio > 20]por valor de un hijo
libro[autor]que tengan al menos un autor
libro[autor[2]]que tengan un segundo autor
libro[titulo/@idioma = 'en']condición sobre un nieto
libro[@categoria = 'novela'][anio > 1950]varios predicados: se aplican en orden
libro[anio < 1950 or precio > 40]con and / or

Cuidado: //autor[1] devuelve el primer autor de cada libro (4 resultados). (//autor)[1] devuelve el primer autor del documento (1 resultado).

3Ejes

child::hijos (eje por defecto): libro = child::libro
attribute::atributos: @id = attribute::id
self::el propio nodo: . = self::node()
parent::padre: .. = parent::node()
descendant::hijos, nietos, bisnietos…
descendant-or-self::lo anterior más el propio nodo (base de //)
ancestor::padre, abuelo… hasta la raíz
ancestor-or-self::lo anterior más el propio nodo
following-sibling::hermanos que vienen después
preceding-sibling::hermanos que vienen antes
following::todo lo que empieza después (salvo descendientes)
preceding::todo lo que acaba antes (salvo ancestros)

4Operadores

= !=igual / distinto
< <= > >=comparación (dentro de un XML escribe &lt;)
and or not()lógicos; not es una función
+ - *suma, resta, multiplicación
div moddivisión y resto (/ se reserva para rutas)
|unión de conjuntos de nodos

Si un lado es un conjunto de nodos, = es cierto cuando alguno cumple: //libro/autor = 'Erich Gamma' es true. Por eso != no es lo contrario de =: usa not(… = …).

5Funciones

Texto

contains(titulo, 'Code')contiene
starts-with(autor, 'R')empieza por
ends-with(titulo, 'ad')termina en (XPath 2.0 o superior)
string-length(titulo)número de caracteres
substring(titulo, 1, 4)desde la posición 1, 4 caracteres
substring-before(autor, ' ')texto antes de un separador
substring-after(autor, ' ')texto después de un separador
concat(autor, ' (', anio, ')')une textos
normalize-space(texto)quita espacios sobrantes
translate(titulo, 'áé', 'ae')sustituye carácter a carácter
upper-case(titulo)mayúsculas (2.0); también lower-case
string(nodo)valor de texto de un nodo

Números

count(//libro)cuántos nodos
sum(//precio)suma
avg(//precio)media (2.0; en 1.0 usa sum() div count())
min(//precio) max(//precio)mínimo y máximo (2.0)
round(2.5) floor() ceiling()redondeos
number('12.50')convierte a número

Nodos y contexto

position() last()posición actual / tamaño del conjunto
name(.) local-name(.)nombre del nodo, con o sin prefijo
distinct-values(//@categoria)valores sin repetir (2.0)
boolean(autor[2])convierte a verdadero o falso
