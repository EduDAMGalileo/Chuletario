La idea en una frase

«Linux» es en rigor solo el núcleo. Lo que instalas y usas es una distribución: el núcleo más un conjunto de programas, un gestor de paquetes y un escritorio, empaquetado por un proyecto.

De un vistazo

Núcleoel corazón: habla con el hardware (Linus Torvalds, 1991)
GNUlas herramientas de sistema que lo rodean
Distribuciónel paquete completo listo para usar: Ubuntu, Debian, Fedora...
Librecódigo abierto: se puede ver, modificar y compartir

1Qué es Linux

Linux es un sistema operativo libre y de código abierto, estilo Unix. Domina en servidores, supercomputadores, móviles (Android usa el núcleo Linux) y dispositivos empotrados; en el escritorio es minoritario pero muy usado en desarrollo y en seguridad.

Multiusuariovarias personas y permisos por usuario y grupo
Multitareamuchos procesos a la vez
Todo es un ficherodiscos, dispositivos y procesos se ven como ficheros
La terminal mandacasi todo se puede hacer y automatizar por línea de comandos

Para el manejo diario del sistema desde la consola, mira Terminal Linux.

2Núcleo, distribución y escritorio

Núcleo (kernel)gestiona CPU, memoria, discos y dispositivos. Es común a todas las distros
Distribuciónnúcleo + programas + gestor de paquetes + instalador, con una filosofía propia
Entorno de escritoriola parte gráfica: GNOME, KDE Plasma, XFCE... se puede cambiar
Gestor de arranqueGRUB: elige qué sistema arrancar
init / systemdel primer proceso; arranca el resto de servicios

Una misma distro puede ofrecer varios escritorios (las «ediciones» o «spins»). El escritorio cambia el aspecto, no el sistema de debajo.

3Las grandes familias

Casi todas las distros descienden de unas pocas «ramas». Saber de qué familia es una distro te dice qué gestor de paquetes usa y cómo se configura.

Debian

Estable y enorme. De ella salen Ubuntu (y de Ubuntu, Linux Mint, Pop!_OS) y Kali (seguridad). Paquetes .deb, gestor APT.

Red Hat

El mundo empresarial: RHEL, y sus derivadas libres Fedora (puntera), CentOS Stream, Rocky y AlmaLinux. Paquetes .rpm, gestor DNF.

Arch

Minimalista y siempre al día (rolling release). Arch y Manjaro. Gestor pacman y el enorme repositorio AUR.

SUSE e independientes

openSUSE (gestor zypper). Fuera de estas ramas: Alpine (muy ligera, típica en contenedores) y Gentoo (se compila todo).

4Gestores de paquetes

Cada familia instala software desde sus repositorios con su propia herramienta. Estas son las equivalencias:

Debian/Ubuntuapt install · apt update · apt remove (paquetes .deb)
Fedora/RHELdnf install · dnf upgrade · dnf remove (paquetes .rpm)
Archpacman -S · pacman -Syu · pacman -R
openSUSEzypper install · zypper update
Alpineapk add · apk update

Flatpak y Snap son formatos que funcionan igual en todas las distros: cada aplicación trae sus dependencias. Cómodos, pero más pesados que el paquete nativo. Más de APT en Terminal Linux.

5Versiones y soporte

Hay dos modelos de publicación:

Versión fijalanzamientos cada cierto tiempo (Debian, Ubuntu, Fedora). Estable y predecible
Rolling releaseactualización continua, sin versiones (Arch). Siempre lo último
LTSLong Term Support: soporte largo (Ubuntu LTS, 5 años). Para servidores y producción
Ubuntuuna versión cada 6 meses (AA.MM); LTS cada 2 años, en abril de los años pares
Debianestable cada ~2 años; también testing y sid (inestable)

Para aprender y para servidores, elige una versión LTS o estable. Las rolling traen lo más nuevo, pero exigen mantenimiento y algún susto de vez en cuando.

7El árbol de directorios

No hay unidades C: como en Windows. Todo cuelga de la raíz /, y los discos y dispositivos se «montan» dentro de ese único árbol (FHS, Filesystem Hierarchy Standard).

/la raíz; todo cuelga de aquí
/homecarpetas personales de cada usuario
/etcficheros de configuración del sistema
/vardatos variables: registros, colas, webs
/usrprogramas y bibliotecas instalados
/bin, /sbinejecutables esenciales
/tmptemporales; se borran al reiniciar
/dev, /proc, /sysdispositivos y estado del núcleo, como ficheros
/mnt, /mediapuntos de montaje de discos y USB

Más detalle de cada carpeta en la sección final de Terminal Linux.

8Elegir distribución

EmpezarUbuntu o Linux Mint: fáciles, mucha documentación en español
ServidorDebian, Ubuntu Server o Rocky/Alma: estables y con soporte largo
SeguridadKali o Parrot: traen las herramientas ya instaladas
Lo últimoFedora (versión fija moderna) o Arch (rolling)
Equipo antiguoXubuntu, Lubuntu o similares con escritorio ligero

Casi todo lo que aprendas vale para cualquier distro: cambian el gestor de paquetes y algún detalle. Este Chuletario usa Debian/Ubuntu (y Kali) como referencia.

9Probar Linux

Máquina virtualVirtualBox o VMware: probar sin tocar tu sistema (lo más recomendable)
Live USBarrancar desde un USB sin instalar nada
WSLLinux dentro de Windows: wsl --install
Arranque dualinstalar junto a Windows y elegir al encender
Contenedordocker run -it ubuntu bash: un Linux de usar y tirar

Para practicar seguridad, monta las máquinas en una red interna aislada de la máquina virtual. Más en la chuleta de Pentest.
