1Permisos

r = 4leer; en carpetas, listar su contenido
w = 2escribir; en carpetas, crear y borrar dentro
x = 1ejecutar; en carpetas, poder entrar
chmod 755 script.shrwxr-xr-x: programas y carpetas
chmod 644 ficherorw-r--r--: ficheros normales
chmod 600 claverw-------: solo tú (claves SSH)
chmod u+x script.shañade ejecución al propietario
chmod go-w ficheroquita escritura a grupo y otros
chmod -R 755 carpetarecursivo
chown ana ficherocambia el propietario
chown -R ana:dam carpetapropietario y grupo, recursivo

u propietario, g grupo, o otros, a todos. Evita chmod 777: da permiso total a cualquiera.

2Usuarios, grupos y sudo

whoamiqué usuario eres
idtu UID y tus grupos
sudo ordenejecuta una orden como administrador
sudo -iabre una shell de root (exit para salir)
su - anacambia al usuario ana
passwdcambia tu contraseña
sudo adduser anacrea un usuario de forma guiada (Debian)
sudo usermod -aG sudo anaañade a ana al grupo sudo
sudo usermod -aG docker anaañade a otro grupo (hay que volver a entrar)
groups anagrupos de un usuario
sudo deluser --remove-home anaborra el usuario y su carpeta
who w lastquién está conectado / últimos accesos

Cuidado: en usermod -aG no olvides la a: sin ella el usuario sale de todos sus otros grupos, incluido sudo.

Usuarios en /etc/passwd, grupos en /etc/group y contraseñas cifradas en /etc/shadow. En las imágenes de Kali para máquina virtual el usuario por defecto es kali con contraseña kali: cámbiala con passwd. Sobre cómo se guardan las contraseñas, ver Criptografía.
