Paquetes y compresión

Instalar y actualizar software con APT, y empaquetar y comprimir con tar, gzip y zip.

1Instalar software con APT

sudo apt updateactualiza la lista de paquetes disponibles
sudo apt upgradeactualiza los paquetes instalados
sudo apt full-upgradeactualiza aunque haya que añadir o quitar paquetes
sudo apt install gitinstala (varios separados por espacios)
sudo apt install ./app.debinstala un .deb descargado con sus dependencias
sudo apt remove gitdesinstala y conserva la configuración
sudo apt purge gitdesinstala y borra la configuración
sudo apt autoremovequita dependencias que ya nadie usa
apt search editorbusca paquetes
apt show gitinformación de un paquete
apt list --installedpaquetes instalados
apt list --upgradablepaquetes con actualización pendiente
dpkg -l | grep javabuscar entre lo instalado
dpkg -L gitficheros que instaló un paquete

Siempre apt update antes de instalar. Los repositorios se configuran en /etc/apt/sources.list y /etc/apt/sources.list.d/. Mezclar repositorios de Ubuntu en Kali (o al revés) suele romper el sistema.

2Comprimir y empaquetar

tar -czvf copia.tar.gz carpeta/crear un .tar.gz
tar -xzvf copia.tar.gzextraer aquí
tar -xzvf copia.tar.gz -C destino/extraer en otra carpeta
tar -tzf copia.tar.gzver el contenido sin extraer
tar -cJvf copia.tar.xz carpeta/crear un .tar.xz (comprime más)
zip -r proyecto.zip proyecto/crear un .zip
unzip proyecto.zip -d destino/extraer un .zip
gzip fichero gunzip fichero.gzcomprimir o descomprimir un solo fichero

Opciones de tar: c crear, x extraer, t listar, z gzip, J xz, v detallado, f fichero (siempre la última).
