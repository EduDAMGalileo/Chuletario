Terminal Linux

En Ubuntu la shell por defecto es bash (~/.bashrc). En Kali es zsh (~/.zshrc). Los comandos de esta página funcionan igual en las dos.

7Permisos

r = 4leer; en carpetas, listar su contenido
w = 2escribir; en carpetas, crear y borrar dentro
x = 1ejecutar; en carpetas, poder entrar
chmod 755 script.shrwxr-xr-x: programas y carpetas
chmod 644 ficherorw-r--r--: ficheros normales
chmod 600 claverw-------: solo tú (claves SSH)
chmod u+x script.shañade ejecución al propietario
chmod go-w ficheroquita escritura a grupo y otros
chmod -R 755 carpetarecursivo
chown ana ficherocambia el propietario
chown -R ana:dam carpetapropietario y grupo, recursivo

u propietario, g grupo, o otros, a todos. Evita chmod 777: da permiso total a cualquiera.

8Usuarios, grupos y sudo

whoamiqué usuario eres
idtu UID y tus grupos
sudo ordenejecuta una orden como administrador
sudo -iabre una shell de root (exit para salir)
su - anacambia al usuario ana
passwdcambia tu contraseña
sudo adduser anacrea un usuario de forma guiada (Debian)
sudo usermod -aG sudo anaañade a ana al grupo sudo
sudo usermod -aG docker anaañade a otro grupo (hay que volver a entrar)
groups anagrupos de un usuario
sudo deluser --remove-home anaborra el usuario y su carpeta
who w lastquién está conectado / últimos accesos

Cuidado: en usermod -aG no olvides la a: sin ella el usuario sale de todos sus otros grupos, incluido sudo.

Usuarios en /etc/passwd, grupos en /etc/group y contraseñas cifradas en /etc/shadow. En las imágenes de Kali para máquina virtual el usuario por defecto es kali con contraseña kali: cámbiala con passwd.

9Instalar software con APT

sudo apt updateactualiza la lista de paquetes disponibles
sudo apt upgradeactualiza los paquetes instalados
sudo apt full-upgradeactualiza aunque haya que añadir o quitar paquetes
sudo apt install gitinstala (varios separados por espacios)
sudo apt install ./app.debinstala un .deb descargado con sus dependencias
sudo apt remove gitdesinstala y conserva la configuración
sudo apt purge gitdesinstala y borra la configuración
sudo apt autoremovequita dependencias que ya nadie usa
apt search editorbusca paquetes
apt show gitinformación de un paquete
apt list --installedpaquetes instalados
apt list --upgradablepaquetes con actualización pendiente
dpkg -l | grep javabuscar entre lo instalado
dpkg -L gitficheros que instaló un paquete

Siempre apt update antes de instalar. Los repositorios se configuran en /etc/apt/sources.list y /etc/apt/sources.list.d/. Mezclar repositorios de Ubuntu en Kali (o al revés) suele romper el sistema.

15Cortafuegos en Ubuntu (ufw)

sudo ufw status verboseestado y reglas
sudo ufw allow sshpermite SSH (hazlo antes de activarlo en remoto)
sudo ufw allow 8080/tcppermite un puerto
sudo ufw deny 3306bloquea un puerto
sudo ufw enableactiva el cortafuegos
sudo ufw status numberedreglas numeradas
sudo ufw delete 2borra la regla 2

En Kali no viene instalado: sudo apt install ufw.

16Comprimir y empaquetar

tar -czvf copia.tar.gz carpeta/crear un .tar.gz
tar -xzvf copia.tar.gzextraer aquí
tar -xzvf copia.tar.gz -C destino/extraer en otra carpeta
tar -tzf copia.tar.gzver el contenido sin extraer
tar -cJvf copia.tar.xz carpeta/crear un .tar.xz (comprime más)
zip -r proyecto.zip proyecto/crear un .zip
unzip proyecto.zip -d destino/extraer un .zip
gzip fichero gunzip fichero.gzcomprimir o descomprimir un solo fichero

Opciones de tar: c crear, x extraer, t listar, z gzip, J xz, v detallado, f fichero (siempre la última).
