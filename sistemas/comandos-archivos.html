Archivos y navegación

Moverse por el sistema de ficheros y trabajar con archivos y carpetas: cd, ls, mkdir, cp, mv, rm y la jerarquía de directorios.

1Moverse por el sistema

pwdcarpeta actual
lslista el contenido
ls -laen detalle e incluyendo ocultos (empiezan por .)
ls -lhtamaños legibles: K, M, G
ls -ltordenado por fecha, lo más reciente primero
cd carpetaentrar en una carpeta
cd ..subir un nivel
cd (o cd ~)ir a tu carpeta personal
cd -volver a la carpeta anterior
cd /ir a la raíz del sistema
tree -L 2árbol de carpetas (sudo apt install tree)

Ruta absoluta: empieza por / (/home/ana/docs). Ruta relativa: parte de donde estás (docs/notas.txt, ../img). ~ es tu home.

2Ficheros y carpetas

touch notas.txtcrea un fichero vacío (o actualiza su fecha)
mkdir fotoscrea una carpeta
mkdir -p a/b/ccrea también las carpetas intermedias
cp origen destinocopia un fichero
cp -r carpeta copiacopia una carpeta entera
cp -i -vpide confirmación / muestra lo que hace
mv viejo.txt nuevo.txtrenombra
mv fichero carpeta/mueve
rm ficheroborra un fichero (no hay papelera)
rm -r carpetaborra una carpeta y su contenido
rmdir carpetaborra una carpeta vacía
ln -s /ruta/real enlacecrea un enlace simbólico (acceso directo)
file foto.pngqué tipo de fichero es realmente
stat ficherotamaño, permisos y fechas

Cuidado: rm -rf borra sin preguntar y sin vuelta atrás. Nunca lo ejecutes con sudo sobre una ruta que no hayas revisado dos veces.

3Ver y editar ficheros

cat ficheromuestra todo el contenido
less ficheropaginado: espacio avanza, / busca, q sale
head -n 20 ficheroprimeras 20 líneas
tail -n 20 ficheroúltimas 20 líneas
tail -f /var/log/syslogsigue el fichero en tiempo real (ver Logs)
wc -l ficherocuenta líneas (-w palabras, -c bytes)
diff a.txt b.txtdiferencias entre ficheros
nano ficheroeditor sencillo
vim ficheroeditor avanzado (ver Vim)

nano

Ctrl+Oguardar
Ctrl+Xsalir
Ctrl+Wbuscar
Ctrl+K Ctrl+Ucortar línea / pegar

vim

imodo inserción (para escribir)
Escvolver al modo normal
:w :q :wqguardar / salir / guardar y salir
:q!salir sin guardar
/textobuscar; n siguiente
dd uborrar línea / deshacer

Para ir a fondo con el editor modal, la chuleta de Vim. Para leer y analizar registros, Logs.

4Carpetas del sistema

La jerarquía estándar de Linux (FHS). Saber qué hay en cada sitio ayuda a no perderse:

/raíz de todo el sistema
/homecarpetas personales de los usuarios
/rootcarpeta personal de root
/etcficheros de configuración
/var/logregistros del sistema y servicios
/var/wwwwebs servidas por Apache o Nginx
/tmptemporales; se vacía al reiniciar
/usr/binprogramas instalados
/usr/sharedatos compartidos (en Kali, /usr/share/wordlists)
/optsoftware instalado a mano
/devdispositivos (/dev/sda, /dev/null)
/procinformación del kernel y procesos en tiempo real
/mnt /mediapuntos de montaje; USB en /media/usuario
/bootkernel y arranque
