Red y acceso remoto

Ver la configuración de red, conectarse por SSH y copiar ficheros, y el cortafuegos sencillo de Ubuntu: ip, ping, ss, ssh, scp, rsync y ufw.

1Red

ip ainterfaces y direcciones IP
ip rtabla de rutas y puerta de enlace
hostname -Isolo las IP del equipo
ping -c 4 google.comcomprobar conectividad (4 paquetes)
ss -tulpnpuertos a la escucha y qué proceso los usa
curl https://ejemplo.comdescarga y muestra una página
curl -I https://ejemplo.comsolo las cabeceras HTTP
wget https://ejemplo.com/f.zipdescarga un fichero
dig ejemplo.comconsulta DNS (nslookup también vale)
traceroute ejemplo.comsaltos hasta un destino
nmcli device statusestado de la red (NetworkManager)
cat /etc/hostsnombres resueltos localmente

ifconfig y netstat son las herramientas antiguas (paquete net-tools). Siguen en Kali, pero lo actual es ip y ss. Configuración de red en detalle en Redes.

2SSH y copia remota

Para aceptar conexiones hay que instalar el servidor: sudo apt install openssh-server. Las claves SSH usan criptografía asimétrica.

3Cortafuegos (ufw)

ufw (Uncomplicated Firewall) es la interfaz sencilla del cortafuegos de Ubuntu, por encima de iptables.

sudo ufw status verboseestado y reglas
sudo ufw allow sshpermite SSH (hazlo antes de activarlo en remoto)
sudo ufw allow 8080/tcppermite un puerto
sudo ufw deny 3306bloquea un puerto
sudo ufw enableactiva el cortafuegos
sudo ufw status numberedreglas numeradas
sudo ufw delete 2borra la regla 2

En Kali no viene instalado: sudo apt install ufw. Para el cortafuegos a fondo, ver Cortafuegos, iptables y nftables.
