IP estática con Netplan

Temporal o permanente

Lo que cambias con ip tiene efecto inmediato, pero se pierde al reiniciar o al reiniciar el servicio de red. Para que dure, hay que escribirlo en la configuración del gestor: Netplan, NetworkManager o /etc/network/interfaces.

Usa ip para probar y diagnosticar; cuando funcione, pásalo al fichero.

1Ver la configuración

ip ainterfaces con sus direcciones (ip addr)
ip -br alo mismo, una línea por interfaz
ip -c acon colores
ip -4 a / ip -6 asolo IPv4 o solo IPv6
ip a show enp0s3una interfaz concreta
ip -br linkestado (UP/DOWN) y MAC de cada interfaz
ip -s linkestadísticas: paquetes, errores, descartes
ip rtabla de rutas y puerta de enlace
ip neightabla ARP: IP y MAC de los vecinos
resolvectl statusservidores DNS de cada interfaz
ss -tulpnpuertos a la escucha

Las órdenes de ip se pueden abreviar: ip a = ip addr show, ip r = ip route show, ip l = ip link show.

2Nombres de las interfaces

loloopback: el propio equipo (127.0.0.1)
enp0s3Ethernet (en) en el bus PCI 0 (p0), ranura 3 (s3). Típico de VirtualBox
ens33Ethernet en la ranura 33. Típico de VMware
eno1Ethernet integrada en la placa
wlp2s0wifi (wl)
enx0800…nombre basado en la MAC (adaptadores USB)
eth0nombre antiguo; hoy solo en contenedores, WSL o si se desactivan los nombres predecibles
docker0, virbr0, br0puentes virtuales

Antes de escribir una configuración, comprueba el nombre real con ip -br link. Copiar eth0 de un tutorial es el error más habitual.

Cuidado: sin máscara, ip addr add 192.168.56.10 pone /32, y el equipo no sabrá que el resto de la red está en su mismo segmento.

4ip: rutas y vecinos

Leer la tabla de rutas

default viala puerta de enlace: a dónde va todo lo que no encaja en otra ruta
scope linkred conectada directamente, sin router intermedio
proto dhcpla ruta la ha puesto el DHCP (static, a mano)
metricprioridad cuando hay varias rutas al mismo destino: gana la más baja

5Netplan: el fichero

/etc/netplan/*.yamlla configuración; se leen en orden alfabético
50-cloud-init.yamlel que crea el instalador de Ubuntu Server
01-network-manager-all.yamlel de Ubuntu Desktop: lo delega todo a NetworkManager
renderernetworkd (por defecto) o NetworkManager
ethernets, wifis, bridges, bonds, vlanstipos de interfaz

YAML no admite tabuladores: sangra siempre con espacios (lo habitual son 2) y mantén la misma sangría entre elementos hermanos. Un espacio de más o de menos cambia el significado o rompe el fichero.

6Netplan: DHCP

DHCP, pero con DNS propios

Las mismas claves sirven para DHCP con IPv6 (dhcp6-overrides). Con IPv6 sin DHCP, la dirección se autoconfigura por SLAAC si el router lo anuncia (accept-ra: true).

7Netplan: IP estática

addresseslista de IP con su máscara en notación CIDR
routesrutas; to: default es la puerta de enlace
nameservers.addressesservidores DNS
nameservers.searchdominios que se añaden a los nombres cortos

Obsoleto: gateway4: 192.168.1.1 aparece en muchos tutoriales. Todavía funciona, pero da un aviso; usa routes con to: default.

8Netplan: aplicar los cambios

sudo netplan generatecomprueba la sintaxis y genera la configuración sin aplicarla
sudo netplan tryaplica y, si no pulsas Intro en 120 s, vuelve a la configuración anterior
sudo netplan applyaplica los cambios
sudo netplan --debug applyaplica y explica lo que hace
sudo netplan getmuestra la configuración combinada de todos los ficheros
sudo netplan statusestado actual de las interfaces (Ubuntu 23.04 o posterior)

Si trabajas por SSH, usa siempre netplan try: si te equivocas de IP, perderás la conexión, pero la configuración se deshará sola y podrás volver a entrar.

10NetworkManager (nmcli)

nmcli device statusinterfaces y su conexión
nmcli con showconexiones (perfiles) guardadas
nmcli con show "nombre"todos los parámetros de una conexión
nmcli con up "nombre"activarla (y aplicar cambios)
nmcli con down "nombre"desactivarla
nmcli dev wifi listredes wifi al alcance
nmtuiasistente con menús en la terminal

El nombre de la conexión depende del idioma del sistema (Wired connection 1 en inglés). Míralo con nmcli con show y ponlo entre comillas si tiene espacios. Las conexiones se guardan en /etc/NetworkManager/system-connections/.

11DNS y nombre del equipo

resolvectl statusDNS que usa cada interfaz
resolvectl query ejemplo.comresolver un nombre con systemd-resolved
resolvectl flush-cachesvaciar la caché DNS
sudo resolvectl dns enp0s3 1.1.1.1cambiar el DNS de forma temporal
dig ejemplo.comconsulta DNS detallada (paquete dnsutils)
dig @8.8.8.8 ejemplo.compreguntar a un servidor concreto
hostnamectlver el nombre del equipo
sudo hostnamectl set-hostname srv01cambiarlo de forma permanente

En Ubuntu, /etc/resolv.conf es un enlace a un fichero generado que apunta a 127.0.0.53 (la caché local de systemd-resolved). No lo edites a mano: los DNS se ponen en Netplan o en NetworkManager.

12El equipo como router

Para que una máquina con dos interfaces dé salida a Internet a una red interna hay que activar el reenvío de paquetes y, normalmente, hacer NAT.

En los clientes de la red interna, la puerta de enlace es la IP del router en esa red (por ejemplo, 192.168.56.10). Si usas ufw, el reenvío también se controla en /etc/default/ufw (DEFAULT_FORWARD_POLICY).

13Diagnosticar paso a paso

1ip -br link¿la interfaz está UP?
2ip -br a¿tiene IP y máscara correctas?
3ip r¿hay ruta por defecto?
4ping 192.168.1.1¿llego a la puerta de enlace?
5ping 8.8.8.8¿salgo a Internet?
6ping ubuntu.com¿funciona el DNS?

Si falla el paso 5 pero no el 4, el problema está en el router o en el NAT. Si funciona el 5 y falla el 6, es el DNS. Una IP 169.254.x.x significa que el DHCP no ha respondido.

14Errores típicos

Invalid YAML, found character that cannot start any tokenhay un tabulador o la sangría no cuadra
Permissions for /etc/netplan/… are too openaviso sin importancia: sudo chmod 600 /etc/netplan/*.yaml
`gateway4` has been deprecatedcambia a routes: - to: default
RTNETLINK answers: File existsesa IP o esa ruta ya existe; bórrala antes o usa ip route replace
La IP vuelve a la anterior al reiniciarla pusiste con ip, o cloud-init o NetworkManager la están sobrescribiendo
Tengo IP pero no navegofalta la ruta por defecto o el DNS

Cuidado: no mezcles gestores. Si una interfaz aparece a la vez en Netplan, en /etc/network/interfaces y en NetworkManager, cada uno intentará configurarla a su manera.
