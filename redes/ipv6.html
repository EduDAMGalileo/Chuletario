IPv6

El direccionamiento de 128 bits: notación y abreviación, el prefijo, los tipos de dirección, la autoconfiguración y las diferencias con IPv4.

La idea

IPv6 nació porque las direcciones IPv4 (unos 4300 millones) se agotaron. Usa 128 bits: un espacio prácticamente inagotable, con autoconfiguración y sin necesidad de NAT.

De un vistazo

128 bits8 grupos de 16 bits en hexadecimal
Separadordos puntos : (no el punto de IPv4)
Prefijocasi siempre /64 para una red

1Qué es IPv6

La versión 6 del protocolo IP. Mantiene la idea de IP (identificar equipos y enrutar paquetes) pero amplía el direccionamiento de 32 a 128 bits y simplifica varias cosas del diseño.

128 bits2^128 direcciones (~340 sextillones)
Sin agotamientode sobra para cada dispositivo, sin NAT
Autoconfiguraciónun equipo puede darse dirección solo (SLAAC)
Sin broadcastusa multicast en su lugar

IPv4 e IPv6 conviven: la mayoría de sistemas usan «doble pila» (dual stack), con las dos a la vez. IPv6 no es opcional a largo plazo, pero la transición es lenta.

2Notación

Ocho grupos de cuatro dígitos hexadecimales (16 bits cada uno), separados por dos puntos:

Hexadecimaldígitos 0–9 y a–f (no distingue mayúsculas)
8 grupos8 × 16 = 128 bits
En URLentre corchetes: http://[2001:db8::1]:8080

3Abreviar

Escribir 32 dígitos es incómodo, así que hay dos reglas para acortar:

Ceros a la izquierdase quitan de cada grupo: 0db8 → db8
::sustituye uno o más grupos consecutivos de ceros
Solo una vez:: puede aparecer una sola vez en la dirección

El :: solo puede usarse una vez: si hubiera dos, no se sabría cuántos grupos de ceros representa cada uno. Si hay varios tramos de ceros, se abrevia el más largo.

4El prefijo

Como el CIDR de IPv4: /n indica cuántos bits son de red. En IPv6 lo habitual es /64.

/64una subred estándar; 64 bits de red + 64 de interfaz
/48bloque típico que un ISP asigna a un sitio
/128una sola dirección (un host concreto)
Id de interfazlos últimos 64 bits identifican al equipo en la subred

Con 64 bits de host, una sola subred IPv6 tiene más direcciones que todo internet IPv4. El «subnetting» aquí casi no consiste en ahorrar, sino en organizar (se juega con los bits entre /48 y /64).

5Tipos de dirección

Se reconocen por cómo empiezan:

Global unicast2000::/3 — pública, enrutable en internet
Link-localfe80::/10 — solo en el enlace local; siempre presente
Unique local (ULA)fc00::/7 (fd00::/8) — privada, como las de IPv4
Multicastff00::/8 — a un grupo de equipos (sustituye al broadcast)
Loopback::1 — el propio equipo (localhost)
Sin especificar:: — «cualquiera / ninguna»

La link-local (fe80::) la tiene toda interfaz IPv6 y sirve para hablar con los vecinos del mismo enlace (por ejemplo, para encontrar el router). Las ULA (fd00::) son el equivalente a 192.168.x.x.

6Autoconfiguración

Un equipo IPv6 puede obtener dirección sin servidor DHCP, mediante SLAAC: escucha al router (que anuncia el prefijo) y se completa el id de interfaz.

SLAACautoconfiguración sin estado: prefijo del router + id propio
Router Advertisementel router anuncia el prefijo de la subred (protocolo NDP)
EUI-64id de interfaz derivado de la MAC
Privacy extensionsid aleatorio por privacidad (para no exponer la MAC)
DHCPv6alternativa con servidor, cuando se quiere control central

Un equipo suele tener varias direcciones IPv6 a la vez: la link-local, una global por SLAAC y quizá una temporal de privacidad. Es normal.
