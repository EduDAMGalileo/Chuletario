IP estática en Debian

Temporal o permanente

ifconfig y route cambian la configuración al momento, pero se pierde al reiniciar. Lo que está en /etc/network/interfaces se aplica en cada arranque.

net-tools lleva años sin desarrollo activo: aprende también las órdenes de ip, que están en todas las distribuciones. Mira la chuleta Configurar la red.

En Debian, ifconfig está en /sbin: con un usuario normal puede dar command not found. Usa sudo ifconfig o /sbin/ifconfig.

3ifconfig

ifconfig eth0una interfaz concreta

Leer la salida

UP significa que está encendida; RUNNING, que además hay cable o enlace. Las versiones antiguas escribían inet addr:192.168.1.10 Mask:255.255.255.0.

Cuidado: ifconfig no muestra las IP secundarias añadidas con ip addr add (salvo que lleven etiqueta, como eth0:0). Si algo no cuadra, compara con ip a.

Las opciones de netstat son las mismas que las de ss: t TCP, u UDP, l a la escucha, p proceso, n números en lugar de nombres.

6/etc/network/interfaces

auto enp0s3se levanta al arrancar el equipo (y con ifup -a)
allow-hotplug enp0s3se levanta cuando el sistema detecta la interfaz (lo que pone el instalador de Debian)
iface enp0s3 inet …cómo configurarla en IPv4; inet6 para IPv6
loopbacksolo para lo
dhcppedir la IP por DHCP
staticIP fija escrita en el fichero
manuallevantar la interfaz sin IP (puentes, pruebas, órdenes propias)
source …/interfaces.d/*incluye otros ficheros

Aquí la sangría no importa: puedes usar espacios o tabuladores. Las líneas que empiezan por # son comentarios. Detalles completos en man interfaces.

7IP estática

network y broadcast se calculan solos a partir de la IP y la máscara: ponerlos es opcional.

Cuidado: las líneas dns-nameservers y dns-search solo tienen efecto si está instalado el paquete resolvconf. Sin él, se ignoran y hay que escribir los DNS en /etc/resolv.conf.

8DHCP e IPv6

Una misma interfaz puede tener un bloque inet y otro inet6; la línea auto se escribe una sola vez.

9Varias IP y órdenes extra

Dos IP en la misma interfaz

Ejecutar órdenes al levantar o bajar la interfaz

pre-upantes de levantarla; si falla, la interfaz no se levanta
up / post-updespués de levantarla (son sinónimos)
down / pre-downantes de bajarla (son sinónimos)
post-downdespués de bajarla

10Aplicar los cambios

sudo ifup enp0s3levantar la interfaz según el fichero
sudo ifdown enp0s3bajarla
sudo ifup -alevantar todas las marcadas con auto
sudo systemctl restart networkingreiniciar toda la red
ifquery enp0s3cómo ha entendido ifupdown la configuración de esa interfaz
ifquery --statequé interfaces ha levantado ifupdown

ifdown deshace lo que dice el fichero en ese momento. Si lo editas antes de bajar la interfaz, la IP antigua puede quedarse puesta y ifup dará error.

Por SSH: escribe sudo ifdown enp0s3 && sudo ifup enp0s3 en una sola línea. Si lanzas solo ifdown, perderás la conexión y no podrás volver a levantarla.

11DNS y nombre del equipo

nameserverservidor DNS; se consultan en orden y como mucho se usan tres
searchdominios que se prueban con los nombres cortos: ping bd busca bd.aula.local
/etc/hostsnombres resueltos localmente; se consultan antes que el DNS
/etc/hostnamenombre del equipo (se lee al arrancar)
sudo hostname srv01cambiar el nombre hasta el próximo reinicio
nslookup ejemplo.comconsulta DNS sencilla

Para cambiar el nombre de forma permanente, edita /etc/hostname y la línea 127.0.1.1 de /etc/hosts. Si no coinciden, sudo tardará en responder porque no sabe resolver el nombre de su propio equipo.

Cuidado: dhclient, resolvconf y NetworkManager reescriben /etc/resolv.conf. Si tus cambios desaparecen, ponlos en dns-nameservers (con resolvconf instalado) o en la configuración del cliente DHCP.

12Cliente DHCP

sudo dhclient -v enp0s3pedir una IP mostrando el intercambio DHCP
sudo dhclient -r enp0s3liberar la IP concedida
/var/lib/dhcp/dhclient.*.leasesconcesiones recibidas: IP, servidor, DNS, caducidad
/etc/dhcp/dhclient.confconfiguración del cliente

Son los cuatro pasos del protocolo (DORA): Discover, Offer, Request, Ack. Para usar siempre tus propios DNS, añade supersede domain-name-servers 1.1.1.1; en dhclient.conf.

13Wifi

Si el fichero guarda la clave, quita el permiso de lectura a los demás usuarios: sudo chmod 600 /etc/network/interfaces.

14Errores típicos

ifconfig: command not foundfalta net-tools, o estás sin sudo y /sbin no está en tu PATH
Cannot find device "eth0"la interfaz se llama de otra forma (enp0s3…): míralo con ip -br link
RTNETLINK answers: File existsla IP o la puerta de enlace ya estaban puestas; suele pasar con dos gateway en interfaces distintas
ifup: interface enp0s3 already configuredya está levantada: haz ifdown primero
Al reiniciar, la interfaz no tiene IPfalta la línea auto o allow-hotplug
NetworkManager dice «no gestionado»la interfaz está en /etc/network/interfaces y NetworkManager la deja en paz

Si quieres volver a los nombres eth0, añade net.ifnames=0 biosdevname=0 a GRUB_CMDLINE_LINUX en /etc/default/grub, ejecuta sudo update-grub y reinicia. Antes, cambia también los nombres en la configuración de red.

Cuidado: en una Ubuntu con Netplan no configures además /etc/network/interfaces: los dos sistemas se pelearán por la misma interfaz.
