La indentación es la sintaxis: cuatro espacios marcan cada bloque. No hay llaves ni ;.

1Variables y tipos

intentero: 42, -7, 1_000_000
floatdecimal: 9.99, 1.5e3
strtexto: 'hola' o "hola"
boolTrue o False
list, tuplelistas y tuplas
dict, setdiccionarios y conjuntos
Noneausencia de valor

Cuidado: Python distingue mayúsculas: nombre y Nombre son variables distintas. Y no se declara el tipo: se asigna y ya está.

2Cadenas de texto

len(s)longitud
s.upper() s.lower()mayúsculas / minúsculas
s.strip()quita espacios de los extremos
s.replace('a','b')reemplazar
s.split(',')texto a lista
', '.join(lista)lista a texto
s.startswith('http')¿empieza por? También endswith
'sol' in s¿contiene?
s[0] s[-1] s[1:4]indexar y rebanar (slicing)

Las cadenas son inmutables: los métodos devuelven una nueva, no cambian la original.

3Operadores

+ - * /7 / 2 = 3.5 (siempre decimal)
// %división entera y resto: 7 // 2 = 3
**potencia: 2 ** 10 = 1024
== !=igual / distinto (compara valores)
< <= > >=comparaciones; se encadenan: 0 < x < 10
and or notlógicos (en palabras, no símbolos)
in not inpertenencia: 3 in [1,2,3]
is is not¿es el mismo objeto? (para None)
a if c else bcondicional (ternario)

Cuidado: usa is solo con None (if x is None). Para comparar valores, siempre ==.

Cuidado: input() devuelve siempre una cadena. Si esperas un número, conviértelo con int() o float(), o fallará al operar.

5Condicionales

match (Python 3.10+)

El bloque tras los dos puntos va indentado. Lo que se considera «falso»: False, 0, "", [], {} y None.

6Bucles

breaksalir del bucle
continuesiguiente vuelta
for...elseel else se ejecuta si no hubo break

7Listas, tuplas y diccionarios

len(x)número de elementos
lista.sort()ordenar en el sitio; sorted(x) devuelve una copia
lista.pop()saca y devuelve el último
del d['clave']borrar una clave
'clave' in d¿existe la clave?
sum(), max(), min()suma, máximo y mínimo

Cuidado: asignar b = a con una lista no la copia: las dos apuntan a la misma. Para copiar, b = a.copy() o b = a[:].

8Funciones

*argsargumentos posicionales sobrantes (tupla)
**kwargsargumentos con nombre sobrantes (dict)
return a, bdevolver varios valores (como tupla)
lambda x: ...función de una línea

Cuidado: no uses una lista o un dict como valor por defecto (def f(x=[])): se comparte entre llamadas. Usa def f(x=None) y créala dentro.

= vs ==uno asigna, dos comparan
