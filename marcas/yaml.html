Un vistazo

La idea

YAML (YAML Ain't Markup Language) guarda los mismos datos que JSON, pero pensado para que lo escriban y lean personas: sin llaves ni comillas, usando la indentación para la estructura.

1Qué es YAML

Un formato de serialización de datos centrado en la legibilidad. Se usa sobre todo para configuración: Docker Compose, Kubernetes, GitHub Actions, Ansible, etc.

Legiblecasi como texto normal; sin llaves ni comas
Indentadola jerarquía se marca con espacios
Superconjunto de JSONtodo JSON válido es YAML válido
Extensión.yaml o .yml

2Escalares y tipos

Textosin comillas normalmente; con " o ' si hace falta
Números42, 3.14 — sin comillas
Booleanostrue/false, también yes/no
Nulonull o ~

Cuidado: valores como no, on o yes se interpretan como booleanos. Si quieres el texto literal (p. ej. el país «NO» de Noruega), ponlo entre comillas: "NO".

4La indentación

La indentación es la estructura, como en Python. Marca qué está dentro de qué.

Solo espaciosnunca tabuladores; rompen el fichero
Consistente2 espacios por nivel es lo habitual
Alineaciónlos elementos del mismo nivel, a la misma columna
Espacio tras :clave: valor, con el espacio

El error nº1 de YAML: mezclar espacios y tabuladores, o indentar de forma desigual. Configura tu editor para mostrar los espacios y usar solo espacios.

7YAML frente a JSON

LegibilidadYAML gana para editar a mano
ComentariosYAML sí (#); JSON no
Comas y llavesYAML no las necesita; JSON sí
IntercambioJSON gana en APIs y entre programas
Compatibilidadtodo JSON es YAML válido

Regla práctica: YAML para configurar (lo editas tú), JSON para intercambiar (lo generan y consumen programas).

9Errores comunes

Tabuladoresusa solo espacios; los tabuladores rompen el YAML
Falta el espacioclave:valor está mal; es clave: valor
Booleanos sorpresano, yes, on son booleanos: entrecomilla si es texto
Indentación desiguallos hermanos deben alinearse exactamente
Dos puntos en el valorentrecomilla: hora: "10:30"

Valida un YAML con yamllint fichero.yml o pegándolo en un validador en línea. Muchos editores avisan de los errores al vuelo.
