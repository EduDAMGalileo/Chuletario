Un vistazo

La idea

JSON (JavaScript Object Notation) representa datos como pares clave: valor y listas. Es texto plano, lo entiende cualquier lenguaje y es el estándar de facto de las APIs web.

1Qué es JSON

Un formato de texto para intercambiar datos estructurados. Nació de JavaScript, pero hoy es independiente del lenguaje: se usa en APIs, ficheros de configuración (package.json), bases de datos NoSQL y más.

Ligeropoco texto de más, fácil de leer y escribir
Universaltodos los lenguajes lo leen y lo generan
Jerárquicoobjetos y listas se anidan sin límite
Extensión.json, tipo MIME application/json

2Tipos de valores

Cadena"texto" — siempre con comillas dobles
Número42, -3.14, 1.5e3 — sin comillas
Booleanotrue / false
Nulonull
Objeto{ } — pares clave:valor
Array[ ] — lista ordenada

Solo estos seis tipos. No hay fechas (se guardan como texto), ni comentarios, ni funciones.

3Objetos y arrays

4Ejemplo completo

Fíjate: llaves para objetos, corchetes para listas, comillas dobles en todas las claves y en las cadenas, y comas entre elementos (nunca tras el último).

5Reglas estrictas

Comillas doblesobligatorias en claves y cadenas; nada de '
Sin coma final[1, 2, 3,] es un error
Sin comentariosJSON no admite // ni /* */
Claves entre comillas{"edad": 30}, no {edad: 30}
Un solo valor raíznormalmente un objeto o un array

Cuidado: los dos fallos más habituales son la coma sobrante tras el último elemento y usar comillas simples. Ambos rompen el JSON.

6JSON frente a XML

<usuario><nombre>Ana</nombre></usuario>
{"usuario": {"nombre": "Ana"}}
JSONmás compacto, ideal para datos y APIs
XMLmás verboso, con atributos, comentarios y validación por esquema
JSON no tienecomentarios, atributos ni namespaces

Para APIs y configuración, hoy manda JSON. XML sigue en documentos, configuraciones heredadas y donde hace falta validación estricta (ver XML Schema).

7Trabajar con JSON

jq es la navaja suiza para JSON en la terminal (sudo apt install jq). En Python, el módulo json; en JavaScript, JSON.parse() y JSON.stringify().

8Validación

JSON Schema describe la estructura que debe cumplir un JSON, igual que XML Schema hace con XML.

Para comprobar a mano si un JSON es válido: jq . fichero.json falla si hay un error de sintaxis, o pega el texto en un validador en línea.
