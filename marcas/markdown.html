Markdown

La idea

Markdown convierte marcas sencillas de texto en HTML con formato. Escribes # Título o **negrita** y se transforma en un encabezado o en texto en negrita. Legible incluso sin renderizar.

Ejemplo

1Qué es Markdown

Un lenguaje de marcado ligero creado en 2004 para escribir con formato sin apartar las manos del teclado. Se escribe en texto plano y una herramienta lo convierte a HTML.

Legible en crudose entiende aunque no se renderice
A HTMLcada marca equivale a una etiqueta HTML
Extensión.md o .markdown
VariantesCommonMark (estándar), GFM (GitHub)

2Encabezados y párrafos

# … ######encabezados de nivel 1 a 6 (equivalen a <h1>–<h6>)
Línea en blancosepara párrafos
Dos espacios finalessalto de línea dentro del párrafo

Deja un espacio tras el #: # Título, no #Título.

3Énfasis

*texto*cursiva
**texto**negrita
***texto***negrita y cursiva
~~texto~~tachado (GitHub)

4Listas

- · * · +lista sin ordenar
1. 2.lista ordenada
Sangraranida sublistas (2 o 4 espacios)
- [ ] · - [x]casillas de tarea (GitHub)

5Enlaces e imágenes

La imagen es igual que un enlace, pero con ! delante. El texto entre corchetes de la imagen es el texto alternativo (accesibilidad).

6Código

`código`código en línea

7Citas y separadores

>cita (blockquote)
---línea horizontal separadora
\escapar una marca: \* muestra un asterisco literal

8Tablas

|separa las celdas
---fila que separa la cabecera del cuerpo
:--- · :--: · --:alinear a izquierda / centro / derecha

Las tablas son de GitHub Flavored Markdown; no están en el Markdown original, pero las admiten casi todas las plataformas.

9Markdown en GitHub

GitHub Flavored Markdown (GFM) añade extensiones muy usadas:

Tareas- [ ] y - [x]
Tachado~~texto~~
Tablascon |
Menciones@usuario, #42 (issue), SHA
Enlaces automáticoslas URL se enlazan solas
Emoji:rocket: → 🚀

El README.md de un repositorio se escribe en GFM. Ver la chuleta de GitHub.
