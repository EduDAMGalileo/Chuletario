1Configuración inicial

--systemtodos los usuarios del equipo
--globaltu usuario (~/.gitconfig)
--localsolo este repositorio (.git/config). Es la opción por defecto

Prioridad: local > global > system. Saltos de línea: core.autocrlf true en Windows, input en Linux y macOS.

2Crear u obtener un repositorio

git initconvierte la carpeta actual en repositorio
git clone <url>descarga un repositorio remoto
git clone <url> <carpeta>lo descarga en otra carpeta
git remote add origin <url>enlaza tu repositorio con un remoto
git remote -vmuestra los remotos configurados
git remote set-url origin <url>cambia la URL del remoto

3El día a día

git statusqué ha cambiado y en qué estado está
git add <fichero>pasa un fichero a staging
git add .pasa todo lo de la carpeta actual
git commit -m "mensaje"guarda una instantánea
git commit -am "mensaje"add + commit, solo ficheros ya seguidos
git diffcambios que aún no están en staging
git diff --stagedcambios que ya están en staging
git pulltrae y fusiona los cambios del remoto
git pushsube tus commits
git push -u origin mainprimer push: fija la rama de seguimiento
git fetchdescarga cambios del remoto sin fusionar

4Historial

git loghistorial completo
git log --onelineun commit por línea
git log --oneline --graph --allárbol con todas las ramas
git log -p <fichero>cambios de un fichero en cada commit
git show <hash>detalle de un commit
git blame <fichero>quién cambió cada línea y cuándo

5Ramas

git branchlista las ramas locales (* es la actual)
git branch -aramas locales y remotas
git branch <rama>crea una rama sin cambiarte a ella
git switch <rama>cambia de rama
git switch -c <rama>crea la rama y se cambia a ella
git checkout -b <rama>lo mismo, forma clásica
git branch -m <nuevo>renombra la rama actual
git branch -d <rama>borra una rama ya fusionada
git branch -D <rama>borra una rama aunque no esté fusionada
git push -u origin <rama>sube una rama nueva
git push origin --delete <rama>borra la rama en el remoto

Nombres habituales: feature/login, fix/crash-inicio, develop.

6Merge: fusionar ramas

git merge --no-ff <rama>fuerza un commit de merge
git merge --abortcancela un merge a medias
git rebase mainreaplica los commits de tu rama sobre main

Fast-forward: si main no ha avanzado, Git solo mueve el puntero. Si las dos ramas han avanzado, se crea un commit de merge.

7Resolver conflictos

git status1. ver qué ficheros tienen conflicto
(editar)2. deja el código correcto y borra los marcadores
git add <fichero>3. marca el conflicto como resuelto
git commit4. cierra el merge con el mensaje por defecto

8Deshacer cambios

git restore <fichero>descarta cambios que no están en staging
git restore --staged <fichero>saca un fichero de staging
git commit --amendcorrige el mensaje o contenido del último commit
git revert <hash>crea un commit que anula otro (seguro)
git reset --soft HEAD~1deshace el último commit y conserva los cambios
git reset --hard HEAD~1deshace el último commit y borra los cambios

Cuidado: no uses reset ni --amend sobre commits que ya has subido. En ramas compartidas usa revert.

9Stash: guardar trabajo a medias

git stashaparca los cambios sin hacer commit
git stash -m "mensaje"aparca con una descripción
git stash listlista lo aparcado
git stash poprecupera lo último y lo quita de la lista
git stash dropdescarta lo último aparcado

10Etiquetas: versiones y entregas

git taglista las etiquetas
git tag -a v1.0 -m "Entrega 1"crea una etiqueta anotada
git show v1.0muestra qué incluye
git push origin v1.0sube una etiqueta
git push origin --tagssube todas las etiquetas

Las etiquetas no se suben con un git push normal.

11.gitignore

Un patrón por línea. Si el fichero ya estaba en el repositorio: git rm --cached <fichero> y haz commit.

HEAD es el commit o rama actual. origin es el nombre por defecto del remoto. HEAD~1 es el commit anterior. Ayuda de cualquier comando: git <comando> --help.
