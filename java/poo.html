Una clase y un objeto

La clase: el molde

El objeto: cada ejemplar

Los atributos van private y se accede a ellos con métodos públicos: así la clase controla lo que se puede hacer con sus datos. Es lo que se llama encapsulación.

1Partes de una clase

atributodato que guarda cada objeto
constructorse llama al hacer new; mismo nombre que la clase y sin tipo de retorno
métodolo que el objeto sabe hacer
thisel objeto actual; sirve para distinguir el atributo del parámetro
staticpertenece a la clase, no a cada objeto
finalno se puede reasignar

2Modificadores de acceso

privatesolo dentro de la propia clase
(sin nada)las clases del mismo paquete
protectedmismo paquete y clases hijas
publicdesde cualquier sitio

Regla práctica: atributos private, métodos que forman la interfaz de la clase public y el resto lo más cerrado posible.

3Constructores

Si no escribes ningún constructor, Java crea uno vacío. En cuanto escribes uno, ese ya no existe: si lo necesitas, decláralo tú.

4Herencia

extendshereda de una sola clase
super(...)constructor del padre; primera línea del constructor
super.metodo()versión del padre de un método
@Overrideavisa al compilador de que estás redefiniendo; te salva de erratas
final classno se puede heredar de ella
final métodono se puede redefinir

Polimorfismo

Una variable del tipo padre puede guardar objetos de las hijas. El método que se ejecuta lo decide el objeto real, no el tipo de la variable.

5Clases abstractas

De una clase abstracta no se pueden crear objetos: sirve para reunir lo común y obligar a las hijas a implementar lo que falta.

6Interfaces

implementsse pueden implementar varias interfaces
defaultmétodo con cuerpo que heredan las clases
staticmétodo de la interfaz, se llama con su nombre
interfaz funcionalla que tiene un solo método abstracto: se puede usar con lambdas

Clase abstracta frente a interfaz: la clase abstracta comparte estado y comportamiento con sus hijas, la interfaz define un contrato que puede cumplir cualquier clase.

7equals, hashCode y toString

Cuidado: si redefines equals, redefine también hashCode. Si no, tus objetos se comportarán mal dentro de un HashSet o como claves de un HashMap.

Los IDE generan estos tres métodos automáticamente, y un record ya los trae hechos.

8Records

Un record es una clase inmutable pensada para transportar datos: genera constructor, getters, equals, hashCode y toString. No admite herencia.

12Paquetes y organización
