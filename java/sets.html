Las implementaciones de Set

Un set no tiene posiciones: no hay get(i). Se pregunta si algo está (contains) o se recorre entero.

3equals y hashCode

Un HashSet calcula el hashCode para saber en qué "cajón" mirar y luego usa equals para comparar. Si tu clase no redefine los dos, dos objetos con los mismos datos cuentan como distintos.

Cuidado: no modifiques un objeto que ya está dentro de un HashSet si el cambio afecta a su hashCode: queda en el cajón equivocado y contains y remove dejan de encontrarlo.

5TreeSet: navegar por orden

Para usar estos métodos, la variable tiene que ser de tipo TreeSet o NavigableSet, no Set. floor, ceiling... devuelven null si no hay ninguno; first y last lanzan excepción si está vacío.

6TreeSet con Comparator

Cuidado: un TreeSet no usa equals: si el comparador devuelve 0, considera que es el mismo elemento y no añade el segundo. Ordenar alumnos solo por nota haría desaparecer a los que empatan; añade siempre un criterio de desempate.

7EnumSet

Solo admite valores de un enum, los guarda en orden de declaración y es muy rápido (por dentro son bits). Es la forma de expresar "opciones activadas" sin usar enteros con máscaras.
