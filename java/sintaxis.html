6Arrays

Utilidades de la clase Arrays

Arrays.toString(a)lo convierte en texto legible
Arrays.deepToString(m)igual, para arrays de dos dimensiones
Arrays.sort(a)ordena
Arrays.fill(a, 0)rellena con un valor
Arrays.copyOf(a, 10)copia con otro tamaño
Arrays.equals(a, b)compara contenido (== compararía referencias)
Arrays.binarySearch(a, x)busca en un array ya ordenado

Cuidado: acceder a una posición que no existe lanza ArrayIndexOutOfBoundsException. El tamaño de un array no se puede cambiar: si lo necesitas, usa una List.

7Métodos

Java pasa siempre una copia del valor. Si el parámetro es un objeto, la copia apunta al mismo objeto: puedes modificar su contenido, pero no hacer que el original apunte a otro.
