Pila y cola

Pila: último en entrar, primero en salir (LIFO)

Cola: primero en entrar, primero en salir (FIFO)

La jerarquía

1Pila (LIFO)

push(e)apila en la cima
pop()saca la cima; NoSuchElementException si está vacía
peek()mira la cima; null si está vacía
isEmpty() size()¿vacía? / cuántos hay

Se declara como Deque: Java no tiene una interfaz Stack aparte. push equivale a addFirst y pop a removeFirst.

2Cola (FIFO)

offer(e)entra por el final
poll()sale el de la cabeza; null si está vacía
peek()mira la cabeza; null si está vacía

Si la variable es Queue, solo se ven los métodos de cola; así nadie puede colarse por delante sin querer.

3Excepción o null: los dos juegos de métodos

Queue tiene cada operación repetida: una versión lanza excepción si no puede, la otra devuelve un valor especial.

 lanza excepcióndevuelve null / false
añadiradd(e)offer(e)
sacarremove()poll()
mirarelement()peek()

Con ArrayDeque y LinkedList, add y offer nunca fallan (no tienen límite). La diferencia importa al sacar y al mirar con la cola vacía, y en las colas con capacidad máxima.

4Deque: doble cola

Deque (double-ended queue, se pronuncia "dec") permite entrar y salir por los dos extremos. Por eso sirve como pila y como cola.

 principio (cabeza)final (cola)
añadiraddFirst offerFirstaddLast offerLast
sacarremoveFirst pollFirstremoveLast pollLast
mirargetFirst peekFirstgetLast peekLast
como pilapush = addFirst · pop = removeFirst · peek = peekFirst
como colaoffer = offerLast · poll = pollFirst · peek = peekFirst

6PriorityQueue

Una cola en la que no sale el primero que llegó, sino el menor según el orden natural o un Comparator. Por dentro es un montículo (heap).

offer addO(log n)
poll remove()O(log n): saca el menor
peekO(1): mira el menor
contains remove(o)O(n)

Cuidado: recorrerla con for-each o imprimirla no la muestra ordenada; solo la cabeza está garantizada. Para obtenerlos en orden, ve haciendo poll(). Y no admite null.

push, pop y peek se llaman igual, así que cambiar de una a otra es casi inmediato. Stack sincroniza cada operación y expone métodos de lista que no tienen sentido en una pila.
