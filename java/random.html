1Math.random()

Devuelve un double en [0, 1): puede salir 0.0, nunca 1.0. Para llevarlo a otro rango se multiplica, se desplaza y se convierte.

Math.random()[0, 1)
* n[0, n)
(int) (...)0, 1, ..., n−1
+ minmin, ..., min+n−1
n = max − min + 1cuántos valores distintos hay

Cuidado: los paréntesis importan. (int) Math.random() * 6 es siempre 0: convierte primero a int el número entre 0 y 1 (que da 0) y luego multiplica.

Math.random() usa por dentro un Random compartido. Random es más cómodo: da enteros directamente, admite semilla y tiene más métodos.

3Semilla: repetir la misma secuencia

Los números de Random son pseudoaleatorios: salen de una fórmula a partir de un valor inicial, la semilla. Con la misma semilla se obtiene siempre la misma secuencia.

Una semilla fija es útil en pruebas (JUnit), simulaciones que hay que poder repetir y para depurar un fallo que aparece "a veces".

6ThreadLocalRandom

Cada hilo tiene su propio generador, así que no se bloquean entre ellos. Es la opción recomendada en programas con varios hilos. No se crea con new ni admite semilla: siempre ThreadLocalRandom.current().

7SecureRandom

Random es predecible: viendo unos cuantos valores se pueden adivinar los siguientes. Para cualquier cosa de seguridad (contraseñas, tokens, claves, códigos de verificación) se usa java.security.SecureRandom.

Es más lento que Random; para juegos o simulaciones no hace falta.

8RandomGenerator (Java 17)

Es la interfaz común que implementan Random, SecureRandom y ThreadLocalRandom. De ahí vienen los métodos con rango nextInt(a, b) y nextDouble(a, b).
