Las clases están en java.nio.file: Path, Files, StandardOpenOption.

1Rutas: la clase Path

Construye las rutas con Path.of("carpeta", "fichero") en vez de escribir "carpeta/fichero": así funcionan igual en Windows y en Linux. La carpeta de trabajo es desde donde se lanza el programa.

2Leer

Files.readString(ruta)todo el contenido en un String
Files.readAllLines(ruta)una lista con las líneas
Files.lines(ruta)stream de líneas (hay que cerrarlo)
Files.newBufferedReader(ruta)lectura línea a línea
Files.readAllBytes(ruta)contenido binario

readAllLines carga el fichero entero en memoria: para ficheros grandes usa lines() o BufferedReader.

3Escribir

CREATEcrea el fichero si no existe (es lo que hace por defecto)
APPENDañade al final en vez de sobrescribir
TRUNCATE_EXISTINGvacía el fichero si ya existía
CREATE_NEWfalla si ya existe

4Gestionar ficheros y carpetas

Files.exists(ruta)¿existe?
Files.isDirectory(ruta)¿es una carpeta?
Files.size(ruta)tamaño en bytes
Files.createFile(ruta)crea un fichero vacío
Files.createDirectories(ruta)crea la carpeta y las que falten
Files.copy(origen, destino)copia
Files.move(origen, destino)mueve o renombra
Files.delete(ruta)borra; falla si no existe
Files.deleteIfExists(ruta)borra si existe
Files.list(carpeta)contenido de una carpeta (un nivel)
Files.walk(carpeta)contenido recursivo

5Entrada por teclado

nextLine()una línea entera, con espacios
next()una palabra
nextInt() nextDouble()un número
hasNextInt()¿lo siguiente es un entero? evita la excepción
useLocale(Locale.US)para leer decimales con punto

Cuidado: con la configuración en español, nextDouble() espera 3,5 y no 3.5. Si mezclas orígenes de datos, fija el Locale.

6Ficheros CSV sencillos

Para CSV de verdad (con comas dentro de los campos, comillas, saltos de línea) usa una librería como OpenCSV o Apache Commons CSV en vez de split.

7Binarios y objetos

La serialización de Java ata el fichero a tus clases. Para intercambiar datos con otros programas es mejor un formato estándar: CSV, JSON o XML.

8Codificación de caracteres

Si al leer un fichero aparecen caracteres raros donde había tildes, casi siempre es un problema de codificación: el fichero está en ISO-8859-1 y se está leyendo como UTF-8 o al revés.
