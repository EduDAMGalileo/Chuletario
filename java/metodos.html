Métodos y recursividad

Agrupar código reutilizable en métodos: parámetros, devolución, sobrecarga, argumentos variables, ámbito y la técnica de la recursividad.

La idea

Un método es un bloque de código con nombre que se puede llamar cuando haga falta. Evita repetir, organiza el programa y da nombre a cada tarea.

Anatomía

1Definir un método

Modificadorespublic, private, static...
Tipo de retornolo que devuelve, o void si nada
Nombreverbo en minúscula: calcularMedia
Parámetroslos datos que recibe, entre paréntesis

static significa que el método pertenece a la clase, no a un objeto: se llama sin crear una instancia. Los métodos de objeto llegan con la orientación a objetos.

2Parámetros y return

Parámetrola variable declarada en la definición
Argumentoel valor concreto que pasas al llamar
returndevuelve un valor y termina el método
voidsin retorno; return; a secas sale antes

Un método puede tener varios return (por ejemplo, uno por rama de un if), pero todos deben devolver el tipo declarado.

3Sobrecarga

Varios métodos con el mismo nombre pero distintos parámetros. Java elige el que encaja según los argumentos.

Lo que distingue las versiones es la lista de parámetros (número o tipo), no el tipo de retorno: dos métodos que solo se diferencien en lo que devuelven no compilan.

4Argumentos variables

Los varargs (...) permiten pasar un número indeterminado de argumentos; dentro del método se tratan como un array.

Solo puede haber un parámetro ... y debe ser el último. Es lo que usa System.out.printf por dentro.

5Paso por valor

Java pasa siempre una copia del valor. Con un primitivo, el método recibe una copia del número y no puede cambiar el original.

Matiz con objetos: la copia apunta al mismo objeto, así que puedes modificar su contenido (los elementos de un array, los campos de un objeto), pero no hacer que el original apunte a otro. La referencia también va por copia.

6Ámbito

El ámbito (scope) es la zona donde una variable existe: desde donde se declara hasta el final de su bloque { }.

Variable localdeclarada dentro de un método; solo vive ahí
Parámetrolocal al método
De bloquela declarada en un if o for muere al salir del bloque
Atributodeclarado en la clase; visible en todos sus métodos (ver POO)

Las variables locales hay que inicializarlas antes de usarlas: Java no les da valor por defecto (a diferencia de los atributos de un objeto).

7Recursividad

Un método recursivo se llama a sí mismo para resolver una versión más pequeña del problema. Necesita siempre dos cosas:

Caso basecuándo parar (sin él, bucle infinito)
Caso recursivola llamada a sí mismo, acercándose al caso base

Cuidado: sin caso base, o si nunca se alcanza, la recursión no para y agota la pila: StackOverflowError. Toda rama recursiva debe acercarse al caso base.

Lo que se puede hacer con recursión también se puede hacer con un bucle. La recursión brilla en problemas naturalmente recursivos (árboles, «divide y vencerás»); el bucle suele ser más eficiente en memoria.
