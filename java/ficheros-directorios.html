Tres clases, tres papeles

File: la API clásica (java.io)

Un objeto con la ruta y los métodos para trabajar con ella. Aún aparece en mucho código y en muchos exámenes.

Path: la ruta (java.nio.file)

Solo representa la ruta: no comprueba si existe ni toca el disco.

Files: las operaciones (java.nio.file)

Clase con métodos estáticos que reciben un Path. Todo lo que toca el disco lanza IOException.

1File (java.io)

Información

exists()¿existe?
isFile() isDirectory()¿es fichero? ¿es carpeta?
canRead() canWrite()permisos de lectura y escritura
isHidden()¿está oculto?
length()tamaño en bytes (0 si no existe)
lastModified()fecha de modificación en milisegundos
getName()nombre: notas.txt
getParent()carpeta padre como String (getParentFile() como File)
getPath()la ruta tal como se escribió
getAbsolutePath()ruta absoluta
getCanonicalPath()ruta absoluta sin . ni ..

Operaciones

createNewFile()crea el fichero vacío; false si ya existía
mkdir()crea una carpeta (la padre debe existir)
mkdirs()crea la carpeta y todas las que falten
delete()borra; una carpeta solo si está vacía
renameTo(otro)renombra o mueve
list()nombres del contenido (String[])
listFiles()contenido como File[]; admite filtro
File.separator\ en Windows, / en Linux
toPath()convierte a Path

Cuidado: los métodos de File devuelven false o null cuando fallan, en vez de lanzar una excepción. Comprueba siempre el resultado de delete(), mkdir(), renameTo() y listFiles().

2Path y Paths

Path.of(...) Paths.get(...)crea la ruta a partir de uno o varios tramos
getFileName()último tramo
getParent()todo menos el último tramo; null si no hay
getRoot()/ o C:\; null en rutas relativas
isAbsolute()¿es absoluta?
toAbsolutePath()la completa, desde la carpeta de trabajo
normalize()quita los . y ..
toRealPath()absoluta, normalizada y con enlaces resueltos; el fichero debe existir
resolve(otra)añade un tramo al final
resolveSibling(otra)cambia el último tramo
relativize(otra)cómo llegar de esta ruta a la otra
startsWith() endsWith()compara tramos completos, no texto
toFile()convierte a File
toString()la ruta como texto

Cuidado: p.endsWith(".txt") es false, porque compara tramos completos de la ruta. Para la extensión: p.toString().endsWith(".txt") o p.getFileName().toString().endsWith(".txt").

5Files: copiar, mover y borrar

REPLACE_EXISTINGsobrescribe el destino
COPY_ATTRIBUTEScopia también fechas y permisos
ATOMIC_MOVEmueve de golpe o no mueve (misma unidad)
LinkOption.NOFOLLOW_LINKStrabaja con el enlace, no con su destino

Cuidado: Files.copy con una carpeta solo crea la carpeta vacía, no copia su contenido. Files.delete con una carpeta que tiene algo lanza DirectoryNotEmptyException.

6Files: listar y recorrer

list(carpeta)Stream<Path> de un solo nivel
walk(carpeta)Stream<Path> recursivo, incluida la propia carpeta
walk(carpeta, n)recursivo hasta n niveles
find(carpeta, n, filtro)recursivo, filtrando por ruta y atributos
newDirectoryStream(carpeta, "*.txt")un nivel, con patrón glob; se recorre con for-each
walkFileTree(carpeta, visitor)recorrido con control total (al entrar, al salir, en errores)

Árbol de carpetas con File (recursivo)

Cuidado: los streams de list, walk, find y lines mantienen la carpeta o el fichero abiertos. Ciérralos siempre con try-with-resources.

7Atributos y permisos

Con File: setReadable, setWritable, setExecutable y setLastModified. Devuelven boolean.

8Files: leer y escribir de un tirón

readAllBytes(p)todo como byte[]

write(p, lineas)escribe una colección de líneas
write(p, bytes)escribe un byte[]
newBufferedReader(p) newBufferedWriter(p)flujos de caracteres con búfer
newInputStream(p) newOutputStream(p)flujos de bytes
CREATEcrea el fichero si no existe
CREATE_NEWcrea, y falla si ya existe

Sin opciones, escribir equivale a CREATE + TRUNCATE_EXISTING + WRITE: crea o sobrescribe. Todo lo de flujos, búferes, binarios, objetos y acceso aleatorio está en Lectura y escritura.

Para código nuevo, Path y Files: lanzan excepciones con la causa real, copian, manejan enlaces simbólicos y atributos. File sigue siendo necesario con APIs antiguas que lo piden, y es fácil pasar de una a otra.

10Despistes habituales

Ruta relativa que no aparecees relativa a la carpeta desde la que se lanza el programa, no al .java; en un IDE suele ser la raíz del proyecto
Rutas con \\ escritas a manousa Path.of("a", "b") o File.separator
No comprobar lo que devuelve Filedelete() o mkdir() pueden fallar en silencio
listFiles() devuelve nullsi la ruta no es una carpeta o no hay permiso
No cerrar Files.list o walkdeja la carpeta bloqueada, sobre todo en Windows
Borrar una carpeta con contenidohay que vaciarla antes: walk + orden inverso
Comprobar y luego actuarentre exists y createFile otro proceso puede crearlo; captura la excepción
