Las cuatro formas de declarar una clase dentro de otra

Se usan para agrupar una clase con la única que la necesita, ocultarla (private) y, en el caso de las internas, darle acceso a los atributos de la externa. Al compilar generan ficheros como Externa$Interna.class y Externa$1.class.

1Tipos de clases anidadas

Anidada estáticamiembro static de la clase. No está ligada a ningún objeto de la externa. Puede ver lo private static de la externa.
Internamiembro sin static. Cada objeto interno pertenece a un objeto externo y puede usar sus atributos, incluso privados.
Localdeclarada dentro de un método. Solo existe ahí; ve las variables locales que no cambian.
Anónimase declara y se crea a la vez, sin nombre, para usarla una vez. Extiende una clase o implementa una interfaz.

Regla práctica: si la clase anidada no necesita los datos de un objeto de la externa, hazla static. Es más simple y no guarda una referencia oculta a la externa.

3Clases internas

Externa.thisel objeto externo; útil si hay nombres repetidos
externa.new Interna()crear una interna desde fuera
Accesola interna ve todo lo de la externa, y la externa todo lo de la interna, incluido lo privado

Cuidado: desde un método static de la externa (como main) no se puede hacer new Interna(): no hay objeto externo. O creas uno (new Externa().new Interna()) o haces la clase static.

4Clases locales

Cuidado: las clases locales y anónimas solo pueden usar variables locales que sean final o efectivamente finales (que no se modifican después). Si cambias dominio en otra línea, no compila.

6Enumerados

values()array con todas las constantes, en orden
valueOf("X")la constante a partir de su nombre
name()el nombre tal cual se declaró
ordinal()la posición (0, 1, 2...)
compareTo(otro)compara por posición

Un enum es una clase con un número fijo de objetos, creados por Java al cargarla. No se puede hacer new Dia(). Úsalo en lugar de constantes int o String sueltas: el compilador no deja pasar valores que no existen.

8Records

Genera soloatributos private final, constructor, accesores, equals, hashCode y toString
Inmutableno tiene setters; para cambiar algo se crea otro
Herenciaes final y no puede extender otra clase; sí implementar interfaces
Atributos extrasolo static; los de objeto van todos en la cabecera
Uso típicodatos que viajan: resultados, filas de un CSV, mensajes, claves de un Map

Cuidado: la inmutabilidad es superficial. En record Grupo(List<String> alumnos) la lista se puede seguir modificando desde fuera. Cópiala en el constructor compacto: alumnos = List.copyOf(alumnos);

9Sealed y pattern matching

sealed limita quién puede heredar o implementar. A cambio, el compilador sabe que la lista de casos está completa, y si mañana añades una figura, te avisa de todos los switch que no la contemplan.
