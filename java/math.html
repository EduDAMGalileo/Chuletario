Math

La clase java.lang.Math: potencias, raíces, redondeo, división entera, trigonometría y desbordamiento. Y BigDecimal y BigInteger para cuando double y long no bastan.

Lo más usado

Math está en java.lang: no hay que importarla. Todos sus métodos son static, así que se llaman con Math.metodo() y nunca se crea un objeto Math.

2Potencias, raíces y logaritmos

Cuidado: Math.pow(81, 1/4) da 1.0, porque 1/4 es división entera y vale 0. Escribe 1.0/4.

3Redondeo

floor(x)hacia abajo (hacia −∞); devuelve double
ceil(x)hacia arriba (hacia +∞); devuelve double
rint(x)al más cercano; en .5, al par; devuelve double
(int) xtrunca: quita los decimales (hacia 0)

Redondear a n decimales

Cuidado: int n = Math.round(x); no compila con un double, porque devuelve long. Escribe (int) Math.round(x).

4División entera y resto

a / bcon enteros, cociente truncado hacia 0
a % bresto; tiene el signo de a
floorDiv(a, b)cociente redondeado hacia −∞
floorMod(a, b)resto con el signo de b: nunca negativo si b > 0

Cuidado: n % 2 == 1 no detecta los impares negativos (-3 % 2 es -1). Usa n % 2 != 0.

8BigDecimal: decimales exactos

double guarda los decimales en binario y no puede representar exactamente valores como 0.1. Para dinero o cualquier cálculo que tenga que cuadrar al céntimo se usa java.math.BigDecimal.

add subtract multiplysuma, resta, multiplicación
divide(x, escala, modo)división; sin escala lanza excepción si no es exacta (1/3)
setScale(n, modo)deja n decimales
compareTo(x)-1, 0 o 1
negate() abs() pow(n)signo, valor absoluto, potencia
max(x) min(x)mayor y menor
doubleValue() intValue()convertir a primitivo
ZERO ONE TENconstantes
RoundingMode.HALF_UPredondeo escolar: .5 sube
RoundingMode.HALF_EVEN.5 al par (redondeo bancario)
RoundingMode.DOWN UPtruncar hacia 0 / alejarse de 0

Cuidado: new BigDecimal(0.1) (con un double) da 0.1000000000000000055511151231257827... porque arrastra el error del double. Usa el constructor con String o BigDecimal.valueOf.

9BigInteger: enteros sin límite

Mismos nombres de métodos que BigDecimal (add, subtract, multiply, divide, compareTo), y también inmutable.

10Despistes habituales

5 / 2da 2: si quieres 2.5, uno de los dos debe ser decimal
int x = Math.pow(2, 3)no compila: pow devuelve double
int x = Math.round(d)no compila: devuelve long
0.1 + 0.2 == 0.3false: compara con tolerancia o usa BigDecimal
x == Double.NaNsiempre false: usa Double.isNaN(x)
Math.sin(90)90 radianes, no grados: Math.toRadians(90)
-7 % 2es -1, no 1: usa floorMod si necesitas positivo
int * int grandese desborda antes de asignarse a long: pon una L
