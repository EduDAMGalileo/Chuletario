La idea

Un array guarda varios valores del mismo tipo en posiciones numeradas. Su tamaño se fija al crearlo y no cambia. Los índices empiezan en 0.

De un vistazo

Tamaño fijose decide al crear; no se puede ampliar
Índicede 0 a length - 1
Longituda.length (atributo, sin paréntesis)

1Declarar y crear

new tipo[n]crea con n posiciones al valor por defecto
{v1, v2, ...}crea e inicializa con esos valores
Números → 0los tipos numéricos empiezan a 0
Objetos → nulllos tipos objeto (String…) empiezan a null
boolean → falselos booleanos, a false

El tipo se puede escribir int[] a (recomendado) o int a[]. El primero deja claro que el tipo es «array de int».

2Acceder y recorrer

Cuidado: acceder a una posición que no existe lanza ArrayIndexOutOfBoundsException. El primer índice es 0 y el último, length - 1.

3Matrices (2D)

Un array de arrays: una tabla con filas y columnas. Se indexa con dos corchetes, m[fila][columna].

m.lengthnúmero de filas
m[f].lengthnúmero de columnas de la fila f
Irregularescada fila puede tener distinta longitud (jagged)

Se pueden tener más dimensiones (int[][][]), pero a partir de dos suele ser mejor una clase o una colección que lo represente con más claridad.

4Utilidades de Arrays

La clase java.util.Arrays trae métodos estáticos para lo habitual:

Arrays.toString(a)lo convierte en texto legible
Arrays.deepToString(m)igual, para arrays de dos dimensiones
Arrays.sort(a)ordena
Arrays.fill(a, 0)rellena con un valor
Arrays.copyOf(a, 10)copia con otro tamaño
Arrays.equals(a, b)compara contenido (== compararía referencias)
Arrays.binarySearch(a, x)busca en un array ya ordenado

Recuerda import java.util.Arrays;. Para comparar o imprimir arrays, usa estos métodos: == y toString() a secas trabajan sobre la referencia, no el contenido.

5Array o List

Arraytamaño fijo, rápido, sintaxis con []; admite primitivos
Listtamaño variable, muchos métodos; solo objetos
¿Cuál?tamaño conocido y fijo → array; si crece o encoge → List

Si necesitas añadir o quitar elementos, empieza directamente con una colección. El array es ideal cuando el número de elementos es fijo y conocido.
