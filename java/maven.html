Qué resuelve

Maven automatiza el ciclo de construir un proyecto Java: descarga las librerías que necesita, compila, ejecuta las pruebas y empaqueta el resultado (un .jar), todo con un comando y una configuración común.

Lo mínimo

1Qué es Maven

Una herramienta de gestión y construcción de proyectos, sobre todo Java. Se basa en el principio de «convención sobre configuración»: si sigues su estructura estándar, apenas hay que configurar nada.

Dependenciasdescarga las librerías y las suyas propias

2Estructura del proyecto

src/main/javael código de la aplicación
src/test/javalas pruebas (JUnit)
target/lo que genera Maven (clases, jar); no se versiona

Respetar estas rutas es lo que evita configurar Maven: busca el código donde por convención debe estar.

3El pom.xml

El Project Object Model: describe el proyecto, sus dependencias y cómo construirlo.

4Coordenadas

Cada proyecto y cada librería se identifica con tres datos (GAV), como una dirección única en el mundo Maven:

groupIdla organización: org.springframework
artifactIdel nombre del proyecto o librería
versionla versión: 3.2.0
packagingel tipo: jar (por defecto), war, pom

Con groupId + artifactId + version, Maven localiza exactamente cualquier librería en los repositorios.

5Dependencias

compiledisponible siempre (por defecto)
testsolo al compilar y ejecutar las pruebas
providedla aporta el entorno (p. ej. el servidor)
runtimesolo al ejecutar, no al compilar

Maven descarga también las dependencias de tus dependencias (transitivas), y resuelve las versiones. Se buscan en mvnrepository.com.

6Repositorios

Centralel repositorio público por defecto (Maven Central)
Local~/.m2/repository: caché de lo ya descargado
Remoto propiode empresa (Nexus, Artifactory)

La primera compilación descarga muchas librerías al .m2 local; las siguientes van rápidas porque ya están en caché.

9Plugins

Maven hace su trabajo a través de plugins. Cada fase del ciclo la ejecuta un plugin; puedes añadir y configurar los que necesites.

compilercompila; fija la versión de Java
surefireejecuta las pruebas
shade / assemblycrea un jar «gordo» con las dependencias dentro
spring-bootempaqueta y ejecuta apps de Spring Boot

Para distribuir una app ejecutable de un solo fichero, el plugin shade mete todas las dependencias dentro del jar.

10Maven o Gradle

Mavenconfiguración en XML, muy estándar y estable; el más extendido
Gradleconfiguración en Groovy/Kotlin, más flexible y rápido; habitual en Android y Kotlin

Los dos hacen lo mismo (dependencias y construcción). Maven es la puerta de entrada clásica en Java; Kotlin y Android suelen usar Gradle.
