Un stream en tres pasos

1origenuna colección, un array, un fichero…
▶
2intermediasfilter, map, sorted… devuelven otro stream
▶
3finaltoList, count, forEach… produce el resultado

Sin operación final no se ejecuta nada: las intermedias solo describen lo que hay que hacer.

1Expresiones lambda

Una lambda solo se puede usar donde se espera una interfaz funcional, es decir, una interfaz con un único método abstracto.

2Interfaces funcionales

Predicate<T>recibe T y devuelve boolean: test(t)
Function<T, R>recibe T y devuelve R: apply(t)
Consumer<T>recibe T y no devuelve nada: accept(t)
Supplier<T>no recibe nada y devuelve T: get()
UnaryOperator<T>recibe T y devuelve T
BiFunction<T, U, R>recibe dos valores y devuelve otro
Comparator<T>compara dos objetos: compare(a, b)
Runnableno recibe ni devuelve nada: run()

4Crear un stream

lista.stream()desde cualquier colección
Arrays.stream(array)desde un array
Stream.of("a", "b")a partir de valores sueltos
IntStream.range(0, 10)0, 1, … 9
IntStream.rangeClosed(1, 10)1, 2, … 10
mapa.entrySet().stream()desde un Map
Files.lines(ruta)las líneas de un fichero
texto.lines()las líneas de un texto
Stream.iterate(1, x -> x * 2)infinito: úsalo con limit

5Operaciones intermedias

filter(p)se queda con los que cumplen la condición
map(f)transforma cada elemento
mapToInt(f)a un stream de int (permite sum(), average())
flatMap(f)aplana: de un stream de listas a un stream de elementos
sorted()ordena por el orden natural
sorted(cmp)ordena con un comparador
distinct()quita repetidos
limit(n) skip(n)los n primeros / se salta los n primeros
peek(c)mira los elementos sin cambiarlos (para depurar)

6Operaciones finales

toList()lista inmutable con el resultado
collect(...)recoge de otras formas (ver la sección siguiente)
forEach(c)hace algo con cada elemento
count()cuántos hay
anyMatch(p)¿alguno cumple?
allMatch(p) noneMatch(p)¿todos? ¿ninguno?
findFirst() findAny()devuelve un Optional
min(cmp) max(cmp)mínimo y máximo, como Optional
reduce(0, Integer::sum)combina todos en un valor
sum() average() summaryStatistics()solo en streams numéricos

7Collectors

Collectors.toList()lista modificable
Collectors.toSet()conjunto
Collectors.joining(", ")une los textos
Collectors.counting()cuenta
Collectors.summingDouble(f)suma
Collectors.averagingDouble(f)media
Collectors.groupingBy(f)agrupa en un Map
Collectors.partitioningBy(p)parte en dos grupos: true y false
Collectors.toMap(k, v)construye un Map

Cuidado: toMap lanza una excepción si se repite una clave. Si puede pasar, indica qué hacer: toMap(k, v, (a, b) -> a).

8Optional

isPresent() isEmpty()¿tiene valor?
get()el valor; falla si está vacío
orElse(x)el valor o una alternativa
orElseGet(() -> x)igual, pero solo calcula la alternativa si hace falta
orElseThrow()el valor o una excepción
ifPresent(c)hace algo solo si hay valor
map(f) filter(p)transforma o filtra el contenido

Optional es la forma de decir «esto puede no existir» sin devolver null. Úsalo como valor de retorno, no como campo de una clase ni como parámetro.

10Despistes habituales

Sin operación finalno se ejecuta nada, ni siquiera los filter
Modificar desde el streamevita cambiar la colección de origen dentro de un forEach
