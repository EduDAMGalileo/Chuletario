7subList y vistas

Cuidado: una subList deja de ser válida si la lista original cambia de tamaño por otro camino: lanza ConcurrentModificationException. Si la vas a guardar, cópiala.

8ArrayList por dentro

Guarda los elementos en un array. Cuando se llena, crea otro un 50 % más grande y copia todo. Por eso get(i) es inmediato y añadir al final casi siempre también, pero insertar o borrar al principio obliga a desplazar el resto.

La capacidad no es el tamaño: new ArrayList<>(100).size() es 0, y get(0) lanza excepción.

9LinkedList

Cada elemento es un nodo con enlaces al anterior y al siguiente. Añadir o quitar en los extremos es inmediato, pero llegar a la posición i obliga a recorrer. Implementa List y también Deque.

Para una pila o una cola es mejor ArrayDeque (ver Pilas y colas). LinkedList solo compensa si insertas o borras mucho en medio usando un iterador, o si necesitas una lista que admita null y además funcione como cola.

10Vector y Stack (antiguas)

Cuidado: son de Java 1.0 y se mantienen por compatibilidad. Sincronizan cada operación (más lentas) y Stack, al heredar de Vector, deja hacer get(i) o add(0, x) en una pila. En código nuevo: ArrayList y ArrayDeque.
