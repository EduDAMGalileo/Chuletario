Ninguna de estas operaciones modifica la lista original: todas devuelven una colección nueva. Son como los streams de Java, pero sin stream() ni collect().

1Lambdas y tipos de función

Una lambda es una función sin nombre que se guarda en una variable o se pasa como argumento. Va entre llaves: parámetros, flecha y cuerpo. La última expresión es lo que devuelve.

(A, B) -> Rfunción que recibe A y B y devuelve R
() -> Unitsin parámetros ni resultado (como Runnable)
itnombre implícito del único parámetro
_parámetro que no se usa: { _, valor -> ... }
::funcionreferencia a una función, propiedad o constructor

2Funciones de orden superior

Funciones que reciben o devuelven otras funciones. Si la lambda es el último parámetro, se escribe fuera de los paréntesis (trailing lambda); si es el único, sobran los paréntesis.

Con inline fun el compilador copia el código de la lambda en el sitio de la llamada: no se crea ningún objeto y dentro se puede usar return para salir de la función de fuera. Casi todas las operaciones de colecciones son inline.

3Crear colecciones

Listordenada, admite repetidos, acceso por posición
Setsin repetidos; setOf mantiene el orden de inserción
Mappares clave → valor; "clave" to valor crea un Pair
Arraytamaño fijo, como los arrays de Java; mejor List salvo para rendimiento

Solo lectura no es inmutable: List no tiene add, pero si por debajo es una MutableList, otro código con acceso a ella puede cambiarla. Y val solo impide reasignar la variable, no cambiar la lista.

12Secuencias

Las operaciones de colecciones crean una lista nueva en cada paso. Una secuencia procesa los elementos de uno en uno por toda la cadena y solo hasta donde haga falta: como un stream de Java.

Para listas pequeñas, las colecciones normales son igual de rápidas y más simples. Usa secuencias con muchos elementos, cadenas largas de operaciones o cuando cortas pronto (take, first).

13Funciones de ámbito

Ejecutan un bloque sobre un objeto. Se diferencian en cómo se llama al objeto dentro (it o this) y en qué devuelven (el resultado del bloque o el propio objeto).

x.let { it... }objeto: it · devuelve: el bloque · para: trabajar con algo que puede ser null (?.let)
x.apply { this... }objeto: this · devuelve: el objeto · para: configurar un objeto recién creado
x.also { it... }objeto: it · devuelve: el objeto · para: algo extra sin cortar la cadena (un log)
x.run { this... }objeto: this · devuelve: el bloque · para: calcular algo con el objeto
with(x) { this... }como run, pero sin ser extensión: varias llamadas sobre el mismo objeto
