Kotlin

Lenguaje moderno sobre la JVM, conciso y seguro frente a nulos. Se usa con las mismas librerías que Java y es el lenguaje oficial de Android.

Sintaxis básicaClases y objetosLambdas y colecciones

La idea

Kotlin compila al mismo bytecode que Java y se ejecuta en la misma JVM: puede usar cualquier clase de Java y mezclarse con ella en el mismo proyecto. Lo que cambia es la forma de escribir: menos código repetitivo, null controlado por el compilador y mucho estilo funcional.

Por dónde empezar

EmpezarSintaxis básica: val y var, when, funciones y nulos
EstructurarClases y objetos: data class, sealed, object, extensiones
Manejar datosLambdas y colecciones: map, filter, groupBy, let, apply

Sin instalar nada: play.kotlinlang.org. En un proyecto, lo normal es Gradle o Maven con IntelliJ IDEA.
